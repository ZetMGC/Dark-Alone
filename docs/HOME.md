# Дом: исследование и события — DA-049

Это черновая TEST-комната и основа будущих домашних эпизодов. Планировка/предметы не утверждают биографию героя, адрес, сюжет, сон или экономику.

## Как попасть и проверить

F5 → завершить смену двумя действиями → «Домой» → закончить/пропустить дорогу. Вместо прежнего плоского экрана откроется 3D-комната. 1 — дверь, 2 — стол, 3 — окно, 4 — кровать; переходы по кольцу в обе стороны. ПКМ/стрелки/R — прежний обзор. E осматривает видимый предмет под прицелом, кнопка «Осмотреть у этой точки» — альтернативный доступ к предмету текущего якоря.

«Завершить осмотр» ставит отметку, «Назад»/Escape отменяет без отметки. Повторное чтение не дублирует её. После стола и окна появляется [TEST] Событие; завершение ставит отдельную одноразовую отметку, отмена оставляет его доступным. Время бара и дневник терминов не меняются. Событие не обязательно для выхода.

J открывает прежнюю книгу и возвращает в комнату/текущий осмотр. Escape вне осмотра открывает общее меню, внутри осмотра сначала отменяет его. Во время модальных экранов камера/взаимодействие дома отключены. Для выхода вернуться к двери (1) и нажать «На работу». На дороге дом скрывается, следующая смена возвращает камеру бара.

## Состав и расширение

- scenes/home/home_exploration.tscn: геометрия из block.tscn, свет, четыре AnchorPoint, четыре HomeObject, отдельные камера/взаимодействие и домашний HUD. Редактировать независимо от бара. Положения якорей — глаза, единичный масштаб; проверить прямой/обратный маршрут и коллизии.
- scripts/home/home_object.gd: Interactable3D с object_id/required_anchor/title/description и сигналом inspect_requested. Каждый объект сейчас привязан к одному якорю. Кнопка осмотра не требует видимости, луч E требует; оба пути повторно проверяют якорь/режим/переход.
- scripts/home/home_state.gd: RefCounted с завершёнными осмотрами/событиями. OBJECTS содержит стабильные ID; EVENTS — только TEST-описания и requires. Прогресс отдельный от определений, геттер событий возвращает копии. Нельзя вызывать код из данных. Конкретные истории/предметы согласовать отдельно.
- scripts/home/home_exploration.gd: координация камеры/HUD/осмотра; соединяется с Session.home, запрашивает дневник/работу через сигналы. Не владеет часами смены.

Для нового тестового предмета добавить стабильный ID в HomeState.OBJECTS и HomeObject в Objects, указать якорь/текст/коллизию; сейчас один предмет на точку для кнопки осмотра. Для нового события добавить уникальный ID и список наблюдений в HomeState.EVENTS. Пока только простое условие «осмотрены все перечисленные предметы» и явное одноразовое завершение. Ветки, награды, инвентарь и произвольные условия не реализованы; их формат/контракт потребуют следующей задачи. После добавления предмета обновить счётчик 4 в HUD/проверках. Формат JSON диалогов не расширялся.

## Прогресс и интеграция

Main создаёт HomeExploration из отдельной сцены. Техническое смещение root=(32,0,0) изолирует коллизии от бара в общем World3D; это не география мира. Переходы происходят под прежним полноэкранным маршрутом, дома выбирается его Camera3D. Барная камера/цели заблокированы. Дом остаётся фоном для книги/меню, его HUD скрыт. Камера дома применяет текущие предпочтения DA-048 при возврате из меню.

Обычная следующая смена передаёт тот же HomeState вместе с Journal через RUN_HANDOFF; технический полный сброс создаёт новый. Прогресс переживает только работу процесса; дисковых сохранений нет. Новые позиционные звуки бара дома выключены по DA-048, прежний общий гул сохраняет исходное поведение.

NarrativeSession.configure_commute(panel, explorable_home=false) сохраняет fallback старого экрана для изолированных потребителей. Main передаёт true: CommutePanel показывает только дорогу, скрытые старые домашние кнопки не подключены к Session. Домашний UI — HomeExploration. Подробнее CONTRACTS/ADR-0018.

## Проверки

tools/check.ps1 включает tests/home_test.gd. Графически: `godot --path . --script tests/home_test.gd -- --capture`; добавить `--small` для 960×600. PNG — artifacts/da049_*.png. Проверяются условия/дубли/копии/повторные сигналы, доступность предметов, оба направления переходов, безопасные позы, ray, отмены/пауза/дневник, события и перенос модели через реальную следующую смену. В редакторе сцену можно редактировать отдельно, игровую интеграцию запускать F5 через Main. Экспорт/человеческая оценка — отдельный следующий шаг.
