# ADR-0052 — устойчивость, наклон и закрытие бутылки

2026-10-29, DA-093. Прямое уточнение владельца после DA-092.

Обычное раскачивание должно затухать к вертикали. TabletopMotion опрокидывает бутылку при боковой скорости тела более 260 логических пикселей/с (после поправки на массу), либо наклоне более 48°. Вертикальная скорость сама по себе не выбирает положение на боку. Плавная интеграция прежняя.

Колесо управляет диапазоном −100…100°, проходя через вертикаль. Струя уже использовала абсолютный наклон; обе стороны используют одну траекторию и один учёт запаса.

Крышка закрывается только при отпускании в небольшой области горлышка: Rect(-21,-10,42,38) в локальных координатах бутылки, по центру крышки. Наведение без отпускания и отпускание на корпусе не закрывают её. Вне горлышка действует физическое падение, включая короткий клик по снятой крышке. Прежний click-to-return заменён этим правилом. Сигнал BottleCapItem.dropped уведомляет DrinkWorkbench до запуска свободного падения. start_motion получил необязательный radians; target_rotation и конечная точка следуют наклонённому горлышку. Анимация 0,26 с имеет небольшой поворот закручивания; бутылка при закрытии не выпрямляется сама. Программный toggle остаётся для управления/тестов.

resting_bottle_streams() возвращает потоки для доступных, не удерживаемых и незакрытых бутылок с наклоном от 65°. При 90° расход 18 мл/с; ниже порога прекращается. advance_pour списывает реальный остаток через DrinkBottleStock.withdraw и добавляет ровно этот состав в DrinkSpillSurface; последняя неполная капля не теряется, отрицательного запаса нет. Отрисовка струй использует тот же поток. Закрытие, подъём, захват, опустошение, скрытие верстака и потеря фокуса прекращают соответствующий расход. Legacy-бутылки считаются открытыми согласно прежнему контракту. При закрытии расход продолжается до завершения анимации.

Потребители: BottleCapItem, DrinkWorkbench, TabletopMotion, small_bottle/tabletop/workbench tests. Тесты баланса одиночного налива ставят остальные бутылки вертикально, чтобы независимые новые проливы не смешивались с измерением одного источника. Ограничения 2.5D и отсутствие взаимных столкновений/разрушения сохраняются. Save-схема не меняется. Уточняет ADR-0051 (пролив теперь реализован, click-to-return заменён).
