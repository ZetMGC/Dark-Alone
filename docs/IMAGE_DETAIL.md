# Детализация изображения — DA-042

Исправление отзыва alpha.1: прежний экранный эффект всегда сводил мир к 360 строкам, в том числе на 4K. Fullscreen уже использовал реальное разрешение, но количество видимых деталей оставалось прежним. Теперь разрешение выборки по умолчанию растёт вместе с экраном; PS1-палитра/материалы/виньетка сохранены.

## Игроку

Escape → «Детализация мира»:

| Режим | Результат |
| --- | --- |
| Под экран — по умолчанию | Блок 2×2 физических пикселя: 360 строк на 720p, 540 на 1080p, 720 на 1440p, 1080 на 4K |
| Чёткая | Каждый пиксель реального кадра, без дополнительного укрупнения; палитра/виньетка остаются |
| Классическая | Прежние 360 строк при любом разрешении; намеренно сильная пикселизация |

«Ретро-изображение» по-прежнему полностью отключает экранный эффект. Детализация запоминается между сменами до закрытия процесса. F11/resize автоматически меняют плотность без перезагрузки мира; время, знания и чтение не меняются. Если эффект выключен, предпочтение детализации сохраняется для следующего включения.

Текст UI расположен над эффектом. Стандартный шрифт интерфейса/3D-надписей и отдельный serif SystemFont книги теперь используют MSDF: глифы масштабируются из расстояний до контура, а не увеличением маленькой растровой маски. Это не меняет размер кнопок/букв, zoom/композицию книги или идентификаторы записей. Файлы сторонних шрифтов не добавлены. Перепагинация использует фактические метрики и прежний reading_offset.

## Разработчику

Shader `retro_screen.gdshader`: `virtual_height=0` и `pixel_block=2` по умолчанию. Сетка берётся из SCREEN_PIXEL_SIZE реального framebuffer, не логической высоты UI 720. Для classic virtual_height=360, для native pixel_block=1. Выборка nearest/LOD 0, без размытия mipmap; цветовой дизеринг неподвижный. Нативный 3D-кадр уже рисуется до эффекта: это изменение видимой детализации, не оптимизация стоимости 3D.

PresentationController: set_image_detail/get_image_detail, значения adaptive/native/classic, `%ImageDetail` в HUD. Main/сессия не получают новых игровых команд. ProjectSettings включает MSDF для default font, book_theme — отдельно для собственного SystemFont. Если добавляется другой шрифт, проверить его настройки самостоятельно.

## Проверить

```powershell
godot --headless --path . --script res://tests/presentation_test.gd
godot --path . res://tests/image_detail_test.tscn -- --capture-dir=<абсолютная-папка>
pwsh -NoProfile -File tools/check_windows_export.ps1 -Godot godot -BuildDirectory <папка-сборки> -Graphics
```

Presentation — 20 проверок режимов/параметров/ошибок/шрифтов/переноса предпочтений/неизменности игры. Графический image_detail_test сравнивает реальный мир в трёх режимах и книгу на 1280×720, 1920×1080, 2560×1440, 3840×2160 и 3440×1440; сохраняет 20 снимков. Числовая GPU-проверка на полосатой мишени подтверждает дополнительные мелкие детали 4K и отсутствие пикселизации текста над эффектом. Без capture-dir — 18 проверок, с 20 снимками — 38. Headless эту проверку пропускает; -Graphics запускает её на release template и требует PASS.

Снимки в `artifacts/da042-compare/`, префикс da042. Сравнивать исходные PNG в 100% масштабе: миниатюра просмотра сама уменьшает 4K. Проверка окон/рендера на одном мониторе не заменяет отзыв владельца на его большом экране или оценку производительности другого GPU. Alpha.1 остаётся прежним опубликованным билдом; исправление поступит в следующий выпуск после слияния/подготовки.
