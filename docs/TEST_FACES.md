# Узнаваемые лица — технический проход DA-035

Подготовлены три нейтральных low-poly TEST-варианта с объёмной анатомией вместо прежней головы из блоков. Это основа для художественной оценки; канонические персонажи, характеры и постоянные портретные привязки до Q-04 не определены.

## Важное уточнение владельца

После этого технического прохода владелец уточнил цель: реалистичные персонажи в близкой стилистике к No, I'm not a Human, возможно чуть менее реалистичные. Нынешние лица временно оставлены, их карикатурная геометрия не утверждена как финальный стиль. Действующий ориентир — CHARACTER_DIRECTION/ADR-0015. DA-035 отложена в todo, финальные личности/портреты требуют Q-04.

## Сравнить в игре

Escape → **[TEST] Лицо гостя** → A / B / C, затем продолжить. Один и тот же гость меняет только внешность; узел разговора, заказ, стакан и время сохраняются. Выбранный TEST-вариант переживает следующую сцену в памяти процесса, после закрытия приложения возвращается A. Настройка экспериментальная для единственного TEST-гостя, не система выбора внешности сюжетного персонажа.

| Вариант | Отличия |
| --- | --- |
| A · Узкое | Вытянутая голова, узкая челюсть, длинная спинка носа, близко посаженные глаза |
| B · Широкое | Широкая челюсть/подбородок, короткая голова, более широкий короткий нос, широкая посадка глаз |
| C · Угловатое | Заострённый подбородок, выраженные скулы, небольшое смещение носа и асимметрия глаз/бровей |

Кожа, волосы и одежда одинаковые. Уши, орбиты, веки, радужки, переносица/крылья носа и губы геометрические. Нет лицевых текстур или заимствованных изображений. Новых коллизий/действий/движения NPC не добавлено. Пока отсутствуют мимика/анимация, индивидуальная одежда и финальная ручная полировка.

## Как устроено

`scenes/characters/test_face.tscn` + `scripts/presentation/test_face.gd`: отдельный Node3D, профили test_face_a/b/c, кольца черепа/челюсти, плоские треугольные грани, детали отдельными низкополигональными мешами. Лицо ориентировано по локальному +X, начало — прежний центр головы TEST-гостя. Координаты не являются мировыми позами. Геометрия строится при ready/смене профиля, не каждый кадр.

`test_guest.tscn`: Body/TestFace заменяет старые Head/Hair/Eyes/Nose/Mouth. Остальное тело, положение, Target и ServiceGuest API сохранены. GuestArt применяет ткань и выбранное лицо, Main связывает `%TestFace` HUD. TestFace.get_profile возвращает копию. Неизвестный appearance_id отклоняется до замены геометрии; старая Anatomy отсоединяется и освобождается, новая одна.

TEST appearance_id обозначает только вариант визуального эксперимента. Он **не character_id**, не запись Journal и не ID диалога. Не переносить глобальное TEST-предпочтение на будущий состав NPC: после Q-04 каждому персонажу нужна отдельная согласованная привязка appearance/portrait, контракт и проверка сохранений. Снимки технического сравнения не являются утверждёнными портретами для сюжета.

## Проверки и снимки

```powershell
godot --headless --path . res://tests/faces_test.tscn
godot --path . res://tests/faces_test.tscn -- --capture-dir=<абсолютная-папка>
godot --path . --script tools/capture_face_preview.gd --resolution 1280x720
godot --path . --script tools/capture_face_preview.gd --resolution 960x600 -- --small
```

faces_test: 22 headless-проверки геометрии/нормалей/копий/ошибочных ID/меню/позы/цели/одежды/разговора/подачи/времени/новой сцены. Графический вариант добавляет сравнение трёх кадров без HUD/подписей при 960×600 и 1920×1080 в adaptive/classic: 38 без записи или 50 с 12 PNG. Разные хеши показывают различие кадров, **не доказывают узнаваемость человеком**.

Инструмент preview создаёт 14 изображений на размер: A/B/C у стойки в двух режимах, меню, фронтальные/трёхчетвертные портреты и общее comparison без подписей в одинаковом свете. `artifacts/da035-faces/`, суффикс `_small` для минимального окна. Настоящее расстояние и освещение бара сохранены. `check_windows_export.ps1 -Graphics` запускает faces_check на release template дополнительно к графике DA-042.
