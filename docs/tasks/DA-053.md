# DA-053: Речь NPC и ответы взглядом

Статус: in_progress. Владелец: агент DA-053. Ветка codex/da053-npc-speech-bubbles, база 2276812; включает ещё не слитые DA-032/DA-052.

Прямой запрос владельца: пузырёк над головой NPC, постепенное появление текста, при отвороте перенос в угол с указанием направления голоса. Варианты ответа появляются при взгляде на NPC; цифра выбирает ответ, колесо меняет выбранный вариант, F подтверждает. Важные слова пока жирные; новую связь выделения с дневником не реализовывать без следующего решения.

Объём: новое представление поверх прежнего Runner/Session, обзор на месте в разговоре без ходьбы, безопасное форматирование важных слов и отдельный сквозной тест. Состояние реплики переживает меню/дневник без повторного набора, ранний F только раскрывает текст; ответ недоступен при отвороте/непрочитанной реплике. Прежние тесты старого интерфейса сохраняются как контрактные. Main и UI-сцены редактирует один агент; рабочая копия на старте чистая, занятых сцен в BACKLOG нет.

Приёмка: видимый пузырёк/угловой указатель/возврат при взгляде; набор и выделение; ответы/конец через клавиши, фильтрация недоступного выбора/повторов; паузы и возобновление; длинные реплики/ответы в 1280×720 и 960×600; часы, знания, прогулка/дом/сохранения не ломаются; исходники и Windows release-template проверены, документация обновлена. Канонический сюжет не придумывать; всё демонстрационное остаётся TEST.
