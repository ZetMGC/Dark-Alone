# ADR-0046 — обратимый перенос бутылок

Принято по запросу владельца, DA-087, 2026-10-29. Бутылка представляет один 3D-узел на полке/в руке/на рабочей поверхности. Добавление в 2D — присутствие в supplied, расход отдельно в stock. Возврат не создаёт бутылку и не пополняет запас. Полка получает отдельную цель размещения, доступную при удержании бутылки. Инструменты/посуда этим изменением не расширены. Состояние пока runtime текущей смены.
