# Переходы дом/работа — DA-031

## Как пройти

Закончить смену → «Домой · закончить день» → трёхсекундный TEST-переход → экран «Между сменами». Здесь можно открыть J/дневник и вернуться. «На работу · новая тестовая смена» запускает обратный переход, затем Main создаётся заново у входа с 2 делениями, пустым дневником и неподанным напитком. Это по-прежнему сброс тестового прототипа; перенос знаний обычной игры запланирован в DA-033.

«Пропустить переход» завершает текущую дорогу один раз. Escape приостанавливает маршрут и открывает меню; «Продолжить» возвращает к нему. В пути нельзя разговаривать, подавать напитки, открывать дневник или переходить по якорям. Прямой тестовый перезапуск из итогов сохранён.

## Границы модулей

`scripts/session/commute_flow.gd` — RefCounted с состояниями at_work/to_home/at_home/to_work/ready, read-only state/trip_id, методами start_home/start_work/complete(id) -> bool. Номер поездки растёт, неподходящие/старые ID и вложенные команды отклоняются. Модель не знает о времени, UI или мире.

`CommutePanel` и `commute_backdrop.gd` — отдельная сцена UI с параллаксом и временным видом дома. travel_seconds=3.0 по умолчанию. Анимация Tween приостанавливается вместе с панелью в меню. И таймер, и пропуск испускают arrived(trip_id); NarrativeSession проверяет режим и модель. CanvasLayer 11 находится ниже дневника, при чтении дома виден только фон без активных кнопок. Фокус остаётся у JournalPanel.

Сессия добавляет optional configure_commute(panel), go_home/go_to_work/finish_commute(id), режимы travel/home и сигнал new_shift_requested. Main слушает готовность обратного пути и перезагружает только текущую сцену с защитой от повторного запроса. Ничего не записывается в user://. Решение — [ADR-0009](decisions/0009-commute-and-journal-order.md).

## Проверка

```powershell
pwsh -NoProfile -File tools/check.ps1 -Godot godot
godot --path . --script tools/capture_commute_preview.gd --resolution 1280x720
godot --path . --script tools/capture_commute_preview.gd --resolution 960x600 -- --small
```

Снимки `artifacts/da031_*.png`: summary, to_home, pause, home, home_journal, to_work, new_shift; `_small` — минимальное окно. Смотреть отсутствие перекрытых кнопок/текста и фон дневника дома. Commute-test проверяет порядок/ID/повторы/паузы и настоящую перезагрузку Main, сквозной тест включает оба пути перезапуска. Экспорт — BUILD.

Графика маршрута — TEST-заготовка, без утверждения географии/событий/дизайна жилья. Реалистичный дневник и узнаваемые лица не реализованы этим этапом: для них отдельный [JOURNAL_PLAN](JOURNAL_PLAN.md). Следующий конкретный шаг — DA-033, контракт записей и перенос знаний между сменами до книжного UI/сохранений.
