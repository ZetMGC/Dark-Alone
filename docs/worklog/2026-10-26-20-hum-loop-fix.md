Найдена ошибка границы PCM: loop_end=44100, а буфер имел только индексы 0…44099. В реализации WAV-микшера закреплённой версии вычисление target включает граничный отсчёт, если он попадает внутрь запрошенного блока. Старый буфер допускал чтение за концом, давая скачок при повторении. Проверено по [исходникам Godot 4.7.2, _mix_internal](https://github.com/godotengine/godot/blob/4.7.2-stable/scene/resources/audio_stream_wav.cpp#L285) и воспроизведено настоящим микшером.

Исправление: выделить (COUNT+1)*2 байт и скопировать первый отсчёт в индекс COUNT. loop_begin/end, тембр, частота 11025 Гц, период 4 с, громкость/управление остаются прежними. Изменены только scripts/presentation/presentation_controller.gd, tests/presentation_test.gd и документация задачи. Публичные API и модели не менялись, новый ADR не требуется.
