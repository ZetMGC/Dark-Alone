# WORKBENCH-01: стойка и свободный верстак

Статус in_progress. Агент владельца, ветка codex/drink-workbench, база 457b3b7. Прямое подтверждение пользователя варианта «Свободный верстак». Область: барная сцена/BackCounter, Main/ServicePanel/Session/GuestService, новые UI/preparation и content/drinks, свои тесты/инструмент/документы. Дома/камеру/HomeState/общие реестры и runner не менять. Общие сцены бара редактирует один агент.

Приёмка: узнаваемая задняя рабочая зона с ковриком/посудой/бутылками/инструментами/сливом, проходимость прежняя. E/B открывает свободную 2D-поверхность: перетаскивание посуды/бутылки, наклон/налив, реальная струя/слои, промах/переполнение, ложка/шейкер/слив; результат отражает реальный состав. Уход/пауза сохраняет стакан без фонового налива. Диалог продолжает говорить, ответы не перехватываются инструментами. Подавать можно только непустую порцию в стакане через прежнюю одноразовую/временную модель, копия результата доступна для будущих рецептов/реакций. Legacy меню/API остаются, проверка нового пути отдельная. Профильные/общие/GPU/чистые проверки и собственная передача обязательны. Рецепты и реакции гостей следующих этапов не выдавать за готовые.
