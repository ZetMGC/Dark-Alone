# 2026-10-28: DA-077 — пузырьки предметов и единая установка

Исполнитель: агент UI, ветка codex/da076-quiet-interface, база 36faab1. Общие сцены правит один агент этой задачи.

## Выполнено

Общий ObjectContextBubble следует проекции реальной поверхности/якоря цели. Доступность/луч проверяются каждый кадр и непосредственно перед командой. Потеря цели, стена, другой ракурс, модальный режим и уход объекта за кадр убирают пузырёк без таймера. UI не захватывает мышь.

Пассивные домашние осмотры (ключи, одежда, мебель, окна, часы, зеркало, душ/санузел) теперь дают сведения без E/модального окна/подтверждения; не изменяют наблюдения/события. Действия изменяющих мир предметов показываются с нумерацией, выбираются цифрами или колесом/F. E сохранена для прямого действия. Отзывы действий остаются у их источника и очищаются при потере взгляда; верхняя угловая подпись для них больше не используется. Реальные события и legacy-действия с прогрессом сохранены.

context_bubble_style.tres разделяется речью, объектами и карточкой стоящей бутылки. Прицел остаётся точкой для пассивного чтения и кольцом для доступного действия. Клавиши контекста не перехватывают ответы в диалоге. Метаданные не входят в save.

Правило единой установки/ярлыка записано в AGENTS. Локальное обновление и запуск завершаются перед передачей; новых пользовательских ярлыков/установок не создаётся.
