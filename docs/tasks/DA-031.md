Итоги → дорога домой → пауза с дневником → дорога на работу → новая тестовая смена. Короткая анимация с пропуском и паузой, безопасные повторные запросы. Файлы: CommuteFlow, CommutePanel/Backdrop, NarrativeSession, Main, Summary/Journal UI, тесты и документация. Бар/гость/материалы не редактируются; Main/Summary — один редактор, агент DA-031, иных владельцев в локальном BACKLOG нет.

Также обработан запрос владельца: составлен JOURNAL_PLAN с порядком DA-033/DA-034 до сохранений/историй и отдельным DA-035 узнаваемых лиц. Книга/новые механики дневника и лица в этой задаче не реализуются.

## Критерии

- [x] До конца смены домой уйти нельзя; переход не тратит время.
- [x] Два маршрута анимированы, можно пропустить, Escape приостанавливает.
- [x] Неверное/старое/повторное завершение безопасно отклоняется.
- [x] Дома доступен старый дневник с правильным возвратом/фоном.
- [x] Новая тестовая смена перезагружает Main один раз, предпочтения оформления сохраняются.
- [x] Полные проверки, визуальный и экспортный проход выполнены.
- [x] Контракты/решение/план и handoff обновлены.
