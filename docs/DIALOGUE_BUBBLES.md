# Пузырьки речи — DA-053

Прямой запрос владельца 2026-10-27: речь NPC над головой, постепенный набор, перенос пузырька в угол при отвороте, ответы при взгляде на NPC, цифры или колесо + F, важные слова жирным. Решение — [ADR-0021](decisions/0021-dialogue-bubbles.md).

## Игроку

Занять место бармена и начать разговор как прежде. Камера остаётся на месте, но мышью и стрелками можно поворачивать голову. Ходьба и выход с рабочего места во время разговора заблокированы.

- Реплика набирается постепенно, по умолчанию 38 символов в секунду. F во время набора показывает текст целиком и не выбирает ответ тем же нажатием.
- Пузырёк привязан к точке над головой NPC. Когда говорящий остаётся за экраном/за спиной, пузырёк переходит в верхний левый или правый угол, появляется направление голоса. Речь продолжает набираться; возвращение взгляда возвращает тот же пузырёк к NPC.
- Варианты появляются после набора реплики при взгляде примерно на лицо (конус 20°), при видимом говорящем и без препятствия. Отворот скрывает варианты и блокирует ответ.
- 1–9 сразу выбирают соответствующий доступный вариант. Колесо переключает доступные варианты с оборачиванием, F подтверждает выбранный. Нумерация сохраняет исходный порядок, недоступный вариант не исполняется. Длинный выбранный ответ автоматически прокручивается в видимую область.
- Последнюю реплику также нужно прочитать/раскрыть, затем F заканчивает разговор. Расход времени происходит только при этом завершении. Backspace прерывает без расхода.
- J — дневник, Escape — меню. Они скрывают пузырёк и ставят набор на паузу, сохраняя текст, место чтения и выбранный ответ. При возврате набранное не начинается сначала. Потеря фокуса также приостанавливает набор/обзор.
- Длинная речь остаётся в ограниченном прокручиваемом пузырьке: PgUp/PgDn позволяют перечитать её. Во время обычного набора текст прокручивается за появляющимися символами.

## Автору текста

В поле `node.text` JSON v1 писать `обычный текст и **важные слова**`. Поддерживается только парное выделение жирным; непарные звёздочки показываются буквально. Другие конструкции, в том числе BBCode/ссылки, остаются текстом и не исполняются. Вложенных стилей/картинок/команд нет. Не использовать ** как буквальную парную последовательность, если выделение не нужно.

Выделение ничего не выдаёт в дневник и не создаёт события. Прежние явно заданные эффекты grant_term работают по старым правилам; будущая фиксация важных слов требует отдельного решения владельца. Текущие реплики и термины остаются TEST, сюжет не добавлен.

## Архитектура и расширение

DialogueBubblePanel наследует DialoguePanel; новая сцена наследует прежнюю. Main включает bubble_enabled при актуальной свободной ходьбе и явно связывает камеру с текущим ServiceGuest через configure_speaker. Для другого NPC перед началом его разговора нужно передать его узел/камеру; автоматического выбора нескольких одновременно говорящих нет.

DialogueRunner/Session по-прежнему отвечают за граф, условия, знания и время. Панель хранит только набор/проекцию/выбранный вариант; команды UI повторно проверяют текущую реплику, видимость панели, взгляд и завершение набора. Программные choose_for_node/finish_for_node остаются API моделей и используются контрактными тестами без ожидания анимации.

FreeRoamCamera.set_dialogue_look позволяет обзор при заблокированном теле; меню/дневник отключают также обзор. Рабочее место вне разговора по-прежнему фиксировано. Legacy fixtures с free_roam_enabled=false используют прежнюю панель/управление; их проверки не заменяют новый dialogue_bubble_test.

DialogueText — безопасное преобразование текста и plain-представление. CheckpointCodec исключает только парные маркеры ** в node.text из отпечатка: оформление не сбрасывает старые знания, точное совпадение прежнего алгоритма проверено. Смена содержания, условий или эффектов по-прежнему делает checkpoint несовместимым. JSON сохранения v1 не изменён, позиция набора/текущий разговор не сохраняются.

Шрифты SystemFont Arial/Noto Sans/DejaVu Sans, normal/700, MSDF. Файлы системных шрифтов не включены в проект/сборку; fallback может отличаться на другой ОС. Размеры пузырька ограничены окном, сцена не растёт вместе с длинной репликой.

## Проверка

`tools/check.ps1 -Godot <Godot 4.7.2>` включает tests/dialogue_bubble_test.tscn. Отдельный графический запуск: `godot --path . res://tests/dialogue_bubble_test.tscn -- --capture-dir=<абсолютная папка>`, `--small` для 960×600. Проверить typing/replies/behind/long-conditional PNG. Экспортный runner получает --bubble-check, обычный EXE не имеет тестового режима. Человеку оценить скорость набора, читаемость жирного и удобство разворота/колеса; отдельный компьютер ещё не проверен.

При завершении/отмене разговора рабочий ракурс восстанавливается к стойке; меню/дневник сохраняют направление взгляда до возврата в разговор.
