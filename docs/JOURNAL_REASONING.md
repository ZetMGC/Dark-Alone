# Слова → готовая группа → вывод → ответ NPC

DA-070 / ADR-0032: UI выбора — компактный popup у точки текущей группы, с tail/hover и динамической высотой строк. Клик выбирает, клик снаружи/Esc закрывает без изменения модели. Выбор цифрами и нумерация удалены по отзыву владельца. get_option_rect(index) по-прежнему в локальных координатах PaperPages, но теперь возвращает реальные popup-строки; неверный индекс даёт пустой Rect2. Потребители: journal_ink_test/capture_reasoning_preview. Модель, JSON/save и публичные сигналы не менялись.

## Уточнение DA-068 / ADR-0031 (действует вместо соответствующих пунктов DA-067)

`NarrativeSession.open_journal(open_pages_immediately: bool = false)` готовит закрытую книгу через `JournalPanel.prepare_book(bool)`. `are_pages_open()` возвращает доступность страниц, `open_cover() -> bool` раскрывает единожды; повтор во время движения отклонён. Подъём закрытой книги не испускает opened/не читает запись. opened приходит после раскрытия; Session блокирует выбор записи, закладку и offset до открытия. Параметр true нужен существующим проверкам страниц/инструментам захвата; игра использует default false. Потребители обновлены в той же задаче. Full/GPU раскрытие использует source закрытой обложки и target того же UI в отдельном viewport, затем прежний settle; pause/reduced/off сохранены.

В `reasoning_groups[].options[]` разрешён optional `required_conclusions: Array[String]`: AND по другим выбранным option_id. Validator проверяет ссылки/дубликаты/ссылки на свою группу и циклы графа групп. До prerequisites опция не выдаётся и choose её отклоняет. `get_groups` добавляет words_ready отдельно от ready: круг появляется по словам, точка — когда есть доступные варианты. Группа/option выбирается один раз. Новый зависимый record дополняется optional `premises` (точные option_id из условия); старые независимые записи остаются из трёх полей. Restore решает цепь в любом порядке атомарно, проверяет предпосылки и evidence; неверные/несовместимые версии не принимаются. Конверт checkpoint v1 и обычный content hash не менялись, demo использует отдельный каталог.

`reasoning_links[].when` optional: `both_conclusions` (default, прежний режим) или `source_conclusion` (источник выбран + достаточно известных слов цели). Условия required_conclusions прежние; несколько условий одной пары можно объявить отдельно, видимая стрелка одна. `get_links(sheet, known: PackedStringArray = [])` принимает слова для нового режима; PaperPages передаёт known IDs. Наличие стрелки/версии не означает истинность.

Вывод рисуется внутри общего контура группы. Arrow использует границу той же superellipse, не координаты подписи; сохранения не содержат пикселей/стрелок. Потребители: Reasoning, Journal, Catalog/Validator, Session, PaperPages/Panel/BookArt, старые fixtures и новый TEST-пакет. [Пример/запуск](REASONING_DEMO.md), [решение](decisions/0031-closed-book-reasoning-chains.md).

**DA-067 — действующий интерфейс, заменяет ручной жест DA-066 ниже.** Круг появляется автоматически при ready, точка у группы открывает варианты. Никакого рисования/письма; подтверждённая версия и evidence прежние. `JournalPaperPages.open_conclusion(group_id) -> bool`, `get_conclusion_button_rect(group) -> Rect2` (видимая точка/область клика), `get_visible_links() -> Array`; скрытая/неполная/уже завершённая группа не открывается. Старое описание замкнутого жеста ниже историческое.

Optional glossary.reasoning_links — до 64 объектов `{"from":"group_a","to":"group_b"}` с optional `"required_conclusions":["option_id"]`. Группы должны существовать на одном развороте, без самоссылок/повторных направленных пар; условия — уникальные существующие ID вариантов. `DialogueCatalog.get_reasoning_links()`, `JournalReasoning.get_link_definitions()/get_links(sheet)` возвращают копии, configure(groups,links=[]) совместим с прежними вызовами. Стрелка появляется только после обоих выводов и всех условий AND. Она не проверяет истинность, не записывается в save отдельно. matches_catalog учитывает определения связей.

`Journal.make_visual_copy() -> Journal` создаёт независимый снимок для рендера целевой страницы; выбор/чтение на копии не меняют оригинал. `JournalPanel` при Full/GPU сначала готовит target в SubViewport с теми же размерами/сценой/темой/шрифтами, затем листает между source/target; на передаче целевое изображение удерживается до реальной раскладки. Временная фаза settle блокирует повторный ввод. Закрытие/смена режима/меню используют прежний serial и отмену; viewport/изображения освобождаются. Preview instance не испускает opened и не меняет глобальный режим анимаций. Новых UI-сигналов Session/формата save нет. При открытии цельная книга поднимается снизу, без масштабирования ширины бумаги/отдельного fade букв; это замена прежней имитации обложки.

Потребители дополнения: Catalog/Validator, Journal/Reasoning, Panel/BookArt/PaperPages, journal_ink_test. Точный актуальный ввод — [JOURNAL_BOOK](JOURNAL_BOOK.md), [ADR-0030](decisions/0030-automatic-groups-stable-pages.md), [протокол](worklog/2026-10-28-04-auto-groups-stable-pages.md). Остальной контракт авторских групп/вариантов/evidence/ответов ниже сохраняется, кроме явно заменённого способа выбора/анимации.

DA-066, ADR-0029. Текущее разрешение владельца: никаких своих текстов или произвольных перемещаемых заметок. Связи и варианты авторские, интерпретацию выбирает игрок. Это заменяет игровую механику DA-065, не стирая старые сохранения.

## Авторский контент

В glossary JSON v1 опциональные reasoning_groups и journal_recipes. Обязательные прежние terms/schema_version/test_content прежние. Пример группы (ID слов должны существовать):

```json
{"id":"test_terms_connection","title":"[TEST] Слова одного разговора","terms":["test_signal","test_marker"],"minimum_terms":2,"sheet":0,"position":[0.24,0.33],"options":[{"id":"test_same_subject","text":"[TEST] Оба слова об одном явлении."},{"id":"test_different_subjects","text":"[TEST] Это независимые явления."}]}
```

Все семь ключей обязательны. До 32 групп, восемь разворотов sheet 0..7, до четырёх групп на разворот. terms — 2..8 уникальных существующих ID, minimum_terms — целое 2..terms.size. position — два конечных числа 0.12..0.85 в долях разворота. Расположение задаёт автор, не семантическая модель; следить за неперекрывающимися областями. options — 2..4 объекта id/text; ID варианта уникален во всех группах, текст 1..240 знаков. Title группы до 100 знаков, не должен раскрывать неизвестное. Слова лучше короткие: UI перестраивает размер/перенос, но это рукописные группы, не длинные абзацы.

До получения слова его нет в визуальной группе. До порога не выдаются варианты. Обводка должна замкнуться, охватить минимум известных слов одной группы, не смешивать соседние группы. Свободная линия — только текущий жест; после принятия контур привязан к группе, не к пикселям, и переживает resize.

Найденная страница рецепта:

```json
{"id":"test_layered_trial","title":"[TEST] Проба двух слоёв","text":"Авторская памятка...","required_terms":["test_marker"]}
```

До 32 страниц по 4000 знаков, только чтение после получения нужных слов. Это текстовый контент, а не распознавание фактического напитка/свободное письмо. В shipped TEST-пакете одна техническая памятка и группа двух исходных терминов; больше групп — по мере появления утверждённого словаря. UI-тест имеет три явно TEST-группы в памяти, не добавляет их в канон.

## Runtime API

DialogueCatalog.get_reasoning_groups()/get_journal_recipes() -> Array: глубокие копии валидированных данных, ошибочный комплект не заменяет каталог.

Journal.get_reasoning_groups(sheet: int) -> Array: только группы с известными словами, terms уже отфильтрованы; ready, options (пусто до порога), conclusion добавлены к копии. Journal.choose_conclusion(group_id: StringName, option_id: StringName, evidence: PackedStringArray=[]) -> bool: проверяет известность/принадлежность/уникальность evidence и порог. Без явного evidence берёт все известные слова этой группы. Journal.has_conclusion(option_id: StringName) -> bool — условие сценария. Journal.reasoning хранит определения/записи и signal changed; get_record/export_data возвращают копии. Повтор/замена уже принятого вывода отклоняются.

Жест/варианты JournalPaperPages существуют только при видимой активной книге вне анимации; скрытый/stale выбор не действует. Набросок при resize/скрытии сбрасывается, открытые варианты сохраняются через меню; при смене раздела — отменяются. Словарь продолжает прежние annotations/reading_offset, неизвестные слова не добавляются выбором вывода. Нет TextEdit/добавления/перетаскивания текста/свободных стрелок. Старый finish_edit оставлен как no-op совместимости Panel, редактора за ним нет.

## Ответы и последствия

В choice диалога необязательный required_conclusions (уникальные существующие option ID):

```json
{"id":"use_conclusion","text":"Я думаю, это разные явления.","target":"different_response","required_conclusions":["test_different_subjects"]}
```

Runner.get_choices добавляет missing_conclusions и available учитывает одновременно required_terms/required_conclusions. choose проверяет условие заново, изменение копии результата его не обходит. Legacy и bubble UI показывают нехватку вывода без технического ID/оценки истинности. Session обновляет реплики при принятии вывода; при закрытии дневника тот же активный Runner/время сохраняются.

content/dialogues/test_reasoning_guest.json — отдельный TEST-диалог test_reasoning_guest_intro. Два интерпретирующих ответа ведут к test_same_response/test_different_response. Штатный test_guest_intro и его источники не изменены; не считать новую демонстрацию написанным основным сюжетом. Для интеграции сюжетных веток автор добавляет required_conclusions к собственным ответам/условиям и сохраняет смысл ID между версиями.

## Сохранение и ограничения

Journal progress получает опциональный conclusions:

```json
[{"group_id":"test_terms_connection","option_id":"test_different_subjects","evidence":["test_signal","test_marker"]}]
```

Пустое поле не экспортируется. Восстановление атомарно, отвергает неизвестный вариант/группу, недостаточную/чужую/дублированную/неизвестную опору и повторный вывод. Checkpoint v1/граница начала следующей смены прежние. Основной content_hash не изменился от добавления метаданных групп/памятки (прежние термины и intro не менялись); ID/условия настоящих диалогов менять с обычной проверкой совместимости. Старый notebook DA-065 остаётся архивным полем, не используется как факт/вывод и не показывается редактором. Новый код читает старые файлы; обратная совместимость старого EXE не обещается.

Пока нет автоматического определения истинности, общего сюжетного графа последствий, перезаписи вывода, свободных стрелок или новой стоимости времени. Конкретные последствия — авторские ветки диалогов, а не новая симуляция мира.

## Анимация и проверка

BookRoot даёт подъём/оседание всей книги; BookArt — обложку/32 полосы изогнутого листа/тень/свет/оборот. GPU использует снимок текущего разворота, preview следующего текста не меняет знание/курсор; commit только по завершении Tween. Full/reduced/off и пауза меню сохранены. Снимок живёт только на время анимации, не сериализуется.
