# DA-020: Данные диалогов и терминов

Статус: done. Владелец: агент DA-020. Ветка: `feat/DA-020-dialogue-content`. Этап: M2. База: `dce5c7f` после слияния M1.

## Результат и границы

Сценарист может описать разговор и словарь в JSON и проверить их без запуска игры. Принятый каталог имеет стабильные ID и не раскрывает частичный результат ошибочной загрузки. Исполнитель реплик, состояние игрока, UI, обслуживание и время в эту задачу не входят.
