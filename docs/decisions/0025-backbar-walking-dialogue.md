# ADR-0025: Задняя рабочая стойка и ходьба в разговоре

Дата: 2026-10-27. Статус: принято по прямому уточнению владельца, DA-059. Заменяет блокировку ходьбы ADR-0021/0024 и расположение рабочей стойки ADR-0024.

Рабочая поверхность находится за спиной бармена у полок. Передний прилавок остаётся мебелью. E по задней поверхности/полкам из прохода открывает локальный back_counter, камера направлена на поверхность под полками. Модель графа/старый counter сохранены только для legacy fixtures; дом не меняется.

В DIALOGUE игровой режим разрешает WASD и обзор с обычными физическими коллизиями. При начале разговора из фокуса Main вызывает leave_focus, возвращая камеру к оставшемуся на месте телу и прежнему взгляду. Пузырёк/набор/страница продолжаются при отходе, за спиной показывается указатель. Отдаление само по себе не отменяет реплику. Ответы по-прежнему требуют взгляда и прямой видимости. Menu/Journal ставят речь и тело на паузу; cancel/finish не возвращают игрока телепортом к стойке. Ходьба бесплатна.

Session/Runner/GuestService API и checkpoint v1 не меняются. Текущий SERVICE остаётся отдельным режимом после разговора. Одновременное приготовление напитков и речь — DA-060, будущая работа: нужен отдельный контракт состояний, ввод/паузы, сохранность реплики и одноразовое списание времени. Рецепты/канон сейчас не утверждаются.

Потребители и проверки — CONTRACTS, WORLD_INTERACTION, FREE_ROAM, DIALOGUE_BUBBLES; world_target_test, dialogue_bubble_test и free_roam_test проверяют текущий путь, legacy наборы сохраняют прежний граф.
