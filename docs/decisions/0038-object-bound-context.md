# ADR-0038 — сведения и действия у предмета

Принято по прямому запросу владельца 2026-10-28. Пассивный осмотр не требует E и не открывает модальное окно. Пузырёк живёт только у текущей видимой доступной цели: нет таймера удержания после потери объекта. Состояние действий остаётся в целевом объекте, UI выводит id/text и повторно проверяет цель перед командой. Номера/колесо/F повторяют механику ответов; в диалоговом режиме список предмета не конкурирует за эти клавиши. Декор общий с речью, без крупных заголовков и кнопок.

Обычные события/чтение, которые записывают игровой прогресс, остаются явными действиями. Новая система не утверждает канон и не меняет формат сохранений. Локальный билд обновляется на месте; опубликованные релизы не заменяются.
