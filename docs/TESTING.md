# Проверки

## Основа — доступно сейчас

Из корня репозитория выполнить `tools/check.ps1`, указав путь к закреплённой версии, если её нет в PATH. Скрипт включает:

```powershell
godot --version
godot --headless --path . --editor --import
godot --headless --path . --script res://tests/smoke_test.gd
godot --headless --path . --quit-after 5
git diff --check
```

Последняя команда выполняется отдельно: она не входит в скрипт Godot. Без PowerShell три команды движка можно запускать напрямую на другой ОС. `godot` здесь — команда или путь к executable. При коде 0 всё равно проверить вывод на ошибки скриптов и ресурсов.

Smoke-тест загружает именно `application/run/main_scene`, создаёт её экземпляр и проверяет вход в дерево. Это узкая проверка готовности основы. Она не подтверждает игровые механики и качество изображения.

Ручной тест M0: открыть проект, нажать F5, убедиться, что видны заголовок, русское сообщение и пояснение; изменить размер окна; закрыть окно. Ошибки редактора и визуальные дефекты записать. Headless-проверка этот тест не заменяет.
