# ADR-0028 — личная бумажная книга

Заменено прямым уточнением владельца: [ADR-0029](0029-journal-conclusions-and-paper-motion.md), DA-066. Свободное письмо/редактирование рецептов — ошибочная интерпретация, игровой редактор удалён; старый notebook только архивный. Ниже история DA-065, не инструкция восстанавливать её механику.

Принято по запросу владельца 2026-10-28, DA-065. Уточняет ADR-0011/JOURNAL-02 и ожидание концепта DA-038. Референс — рукописные овалы/вопросы/стрелки, не источник канона.

Решение: три бумажные закладки «Заметки/Рецепты/Словарь», углы страниц/PgUp/PgDn, закрытие J/Esc или лентой у корешка. Удалить поиск/фильтры/счётчики/панель undo/redo; карандаши и ластик — отдельные предметы, Ctrl+Z/Y сохраняются. Словарь остаётся известными определениями с личным указанием источника; оглавление по восемь слов. Личные заметки можно писать/двигать/обводить/связывать, рецепты — собственные страницы игрока. Связи выражают мысли, не доказанные факты/квестовые условия. Не создавать канонических записей по английскому содержанию референса.

JournalNotebook хранит текст/нормализованные позиции/ID/связи независимо от UI. Journal добавляет необязательное поле notebook в progress только при непустом содержимом. Валидация до мутации: типы/диапазоны/ID/ссылки/дубли/лимиты. Старые checkpoints без notebook/annotations читаются, верхний v1/отпечаток/граница начала следующей смены прежние. Старый EXE не обязан читать новый notebook.

Потребители: JournalPanel/новые PaperPages/WritingTools/BookArt, Main (TextEdit не запускает игровые клавиши), Session (не читает скрытый словарь), journal_core/ink/shift/commute тесты и capture_journal_preview. Search/Section/Count/Matches/InkTool/InkUndo/InkRedo удалены; Close — область ленты, контекст теперь tooltip_text. Description/Index/Bookmark/Previous/Next и сигналы Session сохранены. [Контракт и продолжение](../PERSONAL_JOURNAL.md).

Новые зависимости/картинки извне не нужны: процедурная книга и уже включённый Caveat/OFL. Единственный редактор journal_panel.tscn — агент DA-065, предыдущая дорожка принята DA-063. Распознавание напитков, свободные штрихи, 3D-бумага/руки, сюжетное досье не входят в эту доработку.
