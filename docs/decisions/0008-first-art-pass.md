# ADR-0008: Первый художественный вариант и настройки восприятия

Дата: 2026-10-26. Статус: Accepted для первого прохода DA-030.

## Контекст

После DA-024 владелец попросил продолжить и выбрал Q-02: серый приглушённый бар, люди со сдержанным цветом, пока без видимых рук. Утверждённый ориентир — мрачный PS1 в современной подаче, без переноса материалов Mouthwashing.

## Решение

Сохранить Godot/Compatibility и граф якорей. Вынести декорации/материалы/свет в BarLevel/Art, визуальные изменения гостя — в его Body. Добавленные детали не создают коллизий и не меняют доступность взаимодействия. Поверхности — процедурные пространственные шейдеры с пиксельным рисунком; внешние изображения и новые зависимости не требуются.

Ретро-эффект — отдельный CanvasLayer 2 ниже NavigationHUD (10), модальных панелей и fade (20). Выборка кадра по виртуальной высоте 360, 31 уровень на канал, неподвижный слабый дизеринг и виньетка. Временной шум, тряска и vertex wobble не включены. Это пробные параметры первого варианта; отключение доступно в меню.

Добавить тихий синтезированный гул с регулятором 0…1. На нуле проигрыватель останавливается. Файл звука не нужен: PCM-петля вычисляется один раз на процесс. Настройки PresentationController — static-поля только для пользовательских предпочтений; игровой прогресс остаётся в прежних моделях. При перезапуске смены предпочтения сохраняются, при закрытии процесса сбрасываются. Автозагрузки и сохранения на диск не добавляются.

## Интерфейсы и потребители

Main вызывает `Presentation.configure_controls(hud)` после основной настройки. NavigationHUD предоставляет уникальные узлы RetroCheck, AmbienceVolume, AmbienceLabel. PresentationController: `set_retro_enabled(bool)`, `is_retro_enabled() -> bool`, `set_ambience_gain(float)`, `get_ambience_gain() -> float`. Значения громкости ограничены 0…1, NaN/Inf отклоняются. Панель эффектов не перехватывает мышь. Ни часы, ни дневник, ни JSON v1 не меняются.

## Последствия

Процедурный декор создаётся при запуске, в редакторе до запуска видна базовая геометрия. Числовые параметры и изменение точек описаны в ART_GUIDE. Прежние игровые проверки обязательны вместе с тестом настроек, снимками, графическим и экспортным проходом. Это не финальный персонаж и не готовый M3: сюжет, переход дом/работа и тест целевой машины остаются отдельными задачами.
