# 2026-10-26: DA-049 — дом для исследования и отдельных событий

Исполнитель: агент feat/game-improvements. База 330716a. Прямое поручение: сделать задел дома, где будут отдельные события и исследование. Локальное форматирование project.godot существовало до задачи, не менялось/не включается.

## Выполнено

Отдельная TEST-комната из примитивов: стол/книга, окно, кровать, дверь, свет, коллизии и четыре якоря с круговым двусторонним графом. Своя AnchorCamera применяет общие предпочтения DA-048; E использует общий ray/Interactable3D, альтернативная кнопка осматривает предмет у текущей точки. Дом подключён в HOME после прежнего маршрута, старый домашний экран скрыт. Барная камера/цели не получают ввод, домашний HUD скрывается под книгой/меню, комната остаётся фоном.

HomeState отдельно хранит завершённые осмотры и события, отклоняет неизвестные/повторные/вложенные изменения и отдаёт копии определений. Осмотр/событие требуют явного завершения, Escape/кнопка отменяют без отметки. Стол+окно открывают TEST-событие с собственным ID/условиями; сюжет/наград/инвентаря нет. Событие необязательно для выхода. Книга и пауза возвращают к незавершённому осмотру. Выход на работу только у двери вне осмотра/перехода.

Обычная новая смена переносит тот же HomeState вместе с Journal через RUN_HANDOFF; новый Main выбирает камеру бара. Технический полный reset очищает оба прогресса, дисковых записей нет. configure_commute(...,explorable_home=false) совместим с прежними изолированными потребителями; Main передаёт true, скрытые старые домашние команды не подключаются. Камера дополнена apply_preferences без дублирования меню.
