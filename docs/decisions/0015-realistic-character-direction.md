# ADR-0015: Реалистичная подача будущих персонажей

Статус: accepted как направление по прямому уточнению владельца. Реализация отложена владельцем, текущие TEST-лица сохранены. Дата 2026-10-26.

Владелец пояснил, что предыдущая интерпретация DA-035 слишком угловатая/карикатурная. Цель — реалистичные персонажи в близком направлении к No, I'm not a Human, возможно с несколько меньшим реализмом. Технические модели A/B/C не являются подтверждением финального художественного стиля.

Новая CHARACTER_DIRECTION уточняет и заменяет прежнюю неоднозначную формулировку «карикатурно-реалистичные» в части художественной цели. Требование узнаваемости по лицу сохраняется, общий мрачный PS1-мир/современная подача не отменяются. Требуется будущий проход анатомии, собственных/лицензированных текстур, глаз/волос/одежды и света с оценкой одного персонажа в игровом кадре.

По просьбе владельца сейчас сохраняем существующие лица и выпускаем готовую игру. DA-035 отложена в todo; финальные личности/портреты требуют Q-04. Эта задача не добавляет модели/ассеты/зависимости и не обещает готовую реалистичную модель без итераций. API/игровой код не меняются.
