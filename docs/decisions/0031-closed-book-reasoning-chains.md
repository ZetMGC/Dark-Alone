# ADR-0031: закрытый дневник и цепочки интерпретаций

Статус: принято по прямому уточнению владельца 2026-10-28, DA-068.

Контекст: подъём сразу открытой книги не соответствует желаемому действию. Подпись вне круга и стрелки после двух завершённых выводов не позволяют выразить зависимое рассуждение «война → оружие».

Решение: J достаёт закрытую книгу, отдельный клик раскрывает её. До раскрытия страницы недоступны и запись не считается прочитанной. Полный рендер использует прежние стабильные снимки UI и settle; короткий/отключённый режимы сохраняются. API open_journal получает optional bool для проверок прямого чтения.

Вывод — часть контура группы. Авторские варианты могут требовать другие conclusions; условия AND, граф групп ацикличен. Истинность определяет сценарий. Optional source_conclusion показывает связь после первого вывода и готовности слов цели; старый default требует обоих. Зависимый выбор сохраняет premises и evidence, восстановление атомарно и независимо от порядка записей.

По отдельному поручению добавлен вымышленный TEST-разговор с четырьмя реакциями в наследнике Main. Он отключает сохранения/постоянные настройки и не заменяет основной intro/канон. [Запуск и цепочки](../REASONING_DEMO.md), [контракт](../JOURNAL_REASONING.md).

Последствия: автор должен задавать prerequisites и связи явно, автоматической семантической генерации нет. Одна версия на группу без переписывания. Старые независимые save-records читаются, dependent records требуют точных предпосылок. Будущие сюжетные реакции должны проверять conclusion IDs через Runner, не слова/пиксели.
