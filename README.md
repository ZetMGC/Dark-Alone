# Dark Alone

Нарративная 3D-игра от первого лица: бар в антиутопическом мире, перемещение камеры по якорям, разговоры с гостями и дневник неизвестных терминов.

**Состояние:** M0 — основа репозитория. Игровые механики ещё не реализованы. Название Dark Alone взято из имени рабочей папки и считается рабочим.

## С чего начать

1. Прочитать [текущее состояние](docs/STATUS.md) и [концепт](docs/CONCEPT.md).
2. Установить **Godot 4.7.2 Standard**, язык проекта — GDScript. Версия закреплена в [`.godot-version`](.godot-version); обновлять её отдельным решением.
3. Импортировать `project.godot` из корня репозитория в Godot и нажать **F6** для открытой сцены или **F5** для проекта. Главная сцена — `scenes/main/main.tscn`.
4. Откроется стартовый экран с состоянием проекта. Это проверка основы, а не игровой прототип.
5. Выбрать задачу в [BACKLOG](docs/BACKLOG.md), прочитать [правила совместной работы](CONTRIBUTING.md). Агентам обязательно прочитать [AGENTS.md](AGENTS.md).

Официальная загрузка закреплённой версии: [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/). Нужна Standard-сборка, без .NET. Экспортные шаблоны нужны позже, для сборки дистрибутива.

## Структура

```text
project.godot       Настройки Godot
scenes/main/       Стартовая сцена — точка сборки
scenes/levels/     Локации; пока пусто
scripts/           Код; доменные модули добавлять по мере задач
content/           Диалоги и словарь; пока без утверждённого формата
assets/            Графика, звук и источники; пока пусто
tests/             Проверки; сейчас только запуск главной сцены
tools/             Локальные команды проверки
docs/              Концепт, план, решения, состояние и передача работы
```

Документация — часть результата каждой задачи. Обсуждения в чатах не заменяют изменения в репозитории. Удалённый сервер Git и публичная лицензия пока не настроены.
