# ADR-0007: Проверяемая сборка Windows первого цикла

Дата: 2026-10-26. Статус: Accepted для DA-024.

## Контекст

M2 требует законченный цикл без редактора. Исходная версия проходила headless-тесты, но ещё не имела экспортного пресета. Windows desktop уже используется как рабочая цель; финальная матрица Q-07 остаётся открытой.

## Решение

Экспорт Windows x86_64 с существующим Compatibility renderer, официальными шаблонами закреплённой 4.7.2 и отдельным PCK. JSON явно включается фильтром, инструменты/тесты/документы исключаются из игровой сборки. Архив содержит инструкцию, правовые уведомления движка и manifest с коммитом/dirty/SHA256. Бинарники и локальные пути не коммитятся.

При преобразовании `.tscn` в бинарные сцены в данной среде `AnchorPoint.neighbours` становился пустым массивом: ввод доходил до Main, но переходы отклонялись. В исходном проекте связи сохранены. Отключено только преобразование текстовых ресурсов (`editor/export/convert_text_resources_to_binary=false`); после этого тот же тест проходит в release template. Переключение формата скриптов не устраняло проблему, поэтому оставлен исходный режим 2. Это наблюдаемый обход проблемы экспорта, не утверждение о причине внутри движка. Версия Godot не меняется.

Для сквозной проверки отдельный пресет Windows Validation включает feature integration_test и тестовую стартовую сцену. Тест создаёт настоящий Main, проходит обе ветки, два напитка в разном порядке, дневник/паузу/отмены, итоги и перезапуск. Проверка обычной сборки отдельно запускает её штатный Main. Основной код и сцены мира не получают скрытых тестовых команд.

## Последствия

Исходники, проверочный экспорт и игровой экспорт проверяются раздельно; прохождение в редакторе недостаточно. Возвращать бинарные сцены можно только после повторного прохода экспорта. Дополнительный пресет не является продуктовым режимом игры. Чужой компьютер, физический ввод и удобство остаются командным тестированием по PLAYTEST; ни M3, ни DA-002 этим решением не закрываются.
