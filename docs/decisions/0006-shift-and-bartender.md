# ADR-0006: Рабочая сторона стойки и время смены

Дата: 2026-10-26. Статус: Accepted для DA-023.

## Основание

Владелец указал, что гость оказался на стороне бармена, и попросил исправить стороны/якорь, продолжая план. Для Q-05 владелец выбрал 2 условных деления: завершённый разговор и подача тратят по одному; отмена, перемещение, дневник и меню бесплатны.

## Стойка

Стабильный ID counter и клавиша 2 сохраняются; подпись — «За стойкой». Камера (-4,9; 1,65; -1,2), поворот Y=-90°, смотрит в зал по +X. Стойка сдвинута к X=-3,6, полки сужены: рабочий проход между ними примерно 1,1 м, камера вне коллизий. Гость (-2,5; 1,65; -1,2), поворот 180°, смотрит на бармена. Стакан остаётся на столешнице со стороны гостя. Пятая точка и новые клавиши не нужны.

## Время

ShiftClock — RefCounted-модель, которую настраивают один раз. Уникальный непустой event_id принимается один раз с неотрицательной стоимостью. Нулевые события допустимы в API, но штатные разговор/подача стоят 1. Превышение бюджета даёт остаток 0, не отрицательное значение. После конца события не принимаются; shift_finished испускается один раз после фиксации состояния. Вложенные команды из обработчиков сигналов отклоняются.

NarrativeSession подключает часы отдельной configure_shift после базовой настройки; старые трёхаргументные потребители работают без часов. Каждое принятое start разговора получает уникальный ключ `dialogue:<id>:<serial>`. Только finish списывает время; cancel очищает незавершённый ключ без расхода. У подачи используется существующий `service:<guest_id>`.

Повторно законченный разговор тратит ещё одно деление, хотя термины не дублируются. Поэтому смену можно закончить двумя разговорами без подачи; итог явно сообщает, если гость остался без напитка. Это прототип времени, не утверждённые сюжетные условия победы.

## Конец и новая смена

shift_complete блокирует мир/разговор/подачу и показывает итоговый экран. Дневник можно читать с возвратом к итогам, меню также возвращает к итогам. Новая тестовая смена перезагружает главную сцену: часы, заказ, журнал эффектов и дневник сбрасываются. Это новая сессия без сохранений или перехода «дом — работа».

Основной бюджет экспортирован в Main (2 по умолчанию), для будущих игровых тестов можно менять до запуска. Настройка времени не меняет JSON v1, эффекты grant_term или реальную скорость секунд. Слияние этой ветки включает DA-022, пока его коммит 07bed83 ещё не в origin/main.
