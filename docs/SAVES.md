# Автосохранение между сменами — DA-032

Q-06 принято владельцем 2026-10-27: автосохранение между сменами. Решение — [ADR-0019](decisions/0019-shift-checkpoint.md).

## Поведение игрока

DA-065: личные заметки/их позиции/стрелки и тексты рецептов также переносятся и сохраняются в этой контрольной точке, через опциональный journal.notebook. Старые файлы без notebook/annotations читаются, пустое поле не экспортируется; верхняя версия 1 и content_hash прежние. [Формат/валидация](PERSONAL_JOURNAL.md). Закрытие книги не создаёт немедленного сохранения.

После итогов нужно пройти домой и вернуться на работу. Когда следующая смена успешно открыта, игра сохраняет её начало. После закрытия и запуска восстанавливаются номер смены, знания дневника и домашние наблюдения. Часы снова полные, разговор и заказ новые, камера у входа в бар. Изменения внутри текущей смены и дома попадут в файл только после следующего возвращения на работу. Смена 1 не создаёт checkpoint.

Меню показывает состояние сохранения. «Начать заново…» требует подтверждения и удаляет основной файл, резервный и временные файлы перед запуском смены 1. «Сбросить тестовый прогресс» в итогах также очищает сохранение. Отмена подтверждения ничего не меняет. Если очистка не удалась, сброс не выполняется.

## Файлы и восстановление

Папка `user://checkpoints/`, стандартно на Windows `%APPDATA%/Godot/app_userdata/Dark Alone/checkpoints/`. Фактический путь определяет Godot; локальные абсолютные пути в Git не записываются.

- `shift.json` — текущий checkpoint, максимум 1 МиБ.
- `shift.json.bak` — предыдущий успешно прочитанный checkpoint.
- `.tmp` и `.bak.tmp` — промежуточные файлы, загрузка их игнорирует.

Запись сначала проверяет данные и пишет временный файл. Старый валидный основной файл копируется через временный резервный; затем основной заменяется переименованием. Повреждённый основной не затирает исправный резервный. Ошибка записи сообщается в меню, игра продолжается. Это защита от неполной записи приложением, без гарантии сохранности при сбое питания/файловой системы; одновременный запуск нескольких экземпляров не поддержан блокировкой.

При запуске файл полностью проверяется до установки моделей в игру. Если основной не подходит, проверяется резервный, о восстановлении сообщается в меню. Без исправного файла начинается новая игра с объяснением; исходные файлы сохраняются до следующей успешной записи или явного сброса. Неизвестная версия и изменившийся отпечаток контента несовместимы: автоматической миграции пока нет.

## JSON v1

Корень: `kind="dark_alone_shift_checkpoint"`, `version=1`, `content_hash`, `shift` (2…1000000), `saved_at_utc`, `journal`, `home`. Отпечаток SHA256 включает отсортированный каталог диалогов/терминов и определения домашних объектов/событий. Он намеренно строгий: после изменения контента старый файл может перестать загружаться.

`journal`: упорядоченные `entries` с `id/source/read/bookmarked/reading_offset` и `selected`. Определения терминов берутся из каталога, источник проверяется по диалогу, узлу, говорящему и выдаче термина; смена источника предшествует checkpoint. Курсор — смещение символа исходного текста. `home`: уникальные известные ID `observed/resolved`; событие требует выполненных наблюдений. Не сериализуются ссылки на узлы, текущие виджеты, незавершённые взаимодействия и временные игровые объекты.

Громкость, монитор, детализация, настройки книги и камеры не входят в checkpoint; DA-057 сохраняет их отдельно (PLAYER_SETTINGS). Ручные слоты, сохранение посреди смены, облако и миграции не реализованы.

## Для коллег

Codec восстанавливает новые пустые Journal/HomeState атомарно, без сигналов UI. Main загружает до настройки Session; обычная передача между сценами имеет приоритет над загрузкой с диска. Тестовые Main получают `checkpoint_enabled=false`; проверка сохранений подставляет отдельный Store только в `user://checkpoint_tests/`. Не запускайте интеграционный тест с реальным пользовательским каталогом.

Проверка: `tools/check.ps1 -Godot <Godot 4.7.2>`; затем `tools/check_windows_export.ps1 -Godot <Godot 4.7.2> -BuildDirectory <папка сборки> -Graphics`. Включены отрицательные файлы, резервная копия, ошибка записи, новый процесс и настоящий переход дом → работа. Подробности — [TESTING](TESTING.md).

## Совместимость с DA-052

Ходьба и занятое рабочее место не добавлены в checkpoint. Новая смена/загрузка открывает ходьбу у входа; номер, Journal и HomeState прежние. Отпечаток контента не включает навигацию, существующие файлы v1 совместимы. RUN_HANDOFF переносит free_roam_enabled как конфигурацию сцены, не игровой прогресс на диске. Новый free_roam_test проверяет пеший цикл и повторную загрузку Main из файла.

DA-053: content_hash нормализует парные ** только в node.text. Отпечаток прежнего plain-каталога совпадает с каталогом, где добавлено лишь жирное оформление; это отдельно проверяется по исходной формуле. Остальные поля/содержательные изменения остаются строгими. Версия checkpoint 1, текущий набор/поворот камеры не записываются.
