# ADR-0026: совместная версия бара, дома и книги

Дата 2026-10-27, accepted по прямому поручению владельца DA-063. Origin/main cc1a8e1 содержит принятую домашнюю/дневниковую дорожку; c8988a8 содержит готовый бар. История объединяется merge-коммитом без подмены чужих файлов. Конфликтов текста нет; независимые проверки не заменяют совместный сценарий.

В действующий контракт main включены [барные API](../parallel/bar/CONTRACTS.md), [решения бара](../parallel/bar/DECISIONS.md), [домашние API](../parallel/home/CONTRACTS.md) и [пометки](../parallel/journal/CONTRACTS.md). Исследование барных техник и пределы численной модели — BARTENDING_RESEARCH.md. Родственные ADR-0020/0021/0025 и прежние правила времени сохраняются. Три DrinkPreparation не входят в checkpoint; Journal annotations входят в прежний опциональный прогресс коллеги. Пометки переживают обычную новую смену, но автосохранение по-прежнему на её начале.

Общие check и Windows Validation включают workbench/bar-service/home-targets/house-layout/journal-ink и отдельный release integration. Последний проверяет новый default Main от верстака через редактирование книги и дом до следующей смены. Старый playthrough остаётся проверкой legacy-API. Проверочные аргументы существуют только у Windows Validation entry; Desktop запускает штатную игру.

При интеграции исправлена защита проекции пузырька: голова на плоскости камеры не проецируется, реплика уходит к краю. Это устраняет ошибку движка при повороте на 90°, правила ответов/сюжета не меняет.

Экспортная проверка также выявила side effect внутри assert в HouseInterior._bind: release-template не выполнял register_surface. Регистрация вынесена в обычный код с явной диагностикой. Строгая проверка бытовых действий теперь проходит в release-template. GUI-тест верстака использует только push_input: смешивание с OS warp_mouse давало запаздывающий ввод и срыв кликов при масштабировании окна; продуктовый ввод от этого изменения не меняется.

Релиз alpha.3 создаётся из точного чистого main, с новыми файлами вложений, без замены alpha.1/alpha.2. Сначала проверенный комплект/draft/серверные хеши, затем публикация и скачивание как пользователем. Исходные ограничения — TEST-сюжет, приближённые жидкости, временные лица — сохраняются. Детали фактических проверок — docs/worklog/2026-10-27-14-bar-release-integration.md.
