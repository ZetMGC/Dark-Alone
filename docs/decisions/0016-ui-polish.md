# ADR-0016: Безопасный сброс и контекстное представление

Дата: 2026-10-26. Статус: Accepted для DA-046 по прямому поручению пользователя выполнить пять предложенных улучшений. Ветка: `feat/game-improvements`; слияние/публикация не входят в поручение.

## Решение

- Подтверждение сброса принадлежит ShiftSummaryPanel. Встроенная панель скрывает прежние кнопки; фокус на отмене. Escape отменяет, J/T/B не меняют экран. Скрытие итогов отменяет запрос. Программный Main.restart_shift сохраняет прежний контракт; пользовательская кнопка испускает restart_requested только после подтверждения.
- Main вычисляет рекомендацию из якоря, завершённых событий и подачи; HUD отображает её. Это подсказка, не новый критерий завершения. Два разговора по-прежнему могут завершить смену без напитка.
- Main слушает Journal.term_added, HUD показывает агрегированное уведомление 5 секунд на слое 18. Оно не перехватывает ввод; пауза скрывает и приостанавливает его, дневник очищает уведомление. Новых записей/прочитанности UI самостоятельно не выставляет.
- HUD мира скрывается под модальными экранами, подробные клавиши доступны в меню; в мире остаётся короткая контекстная строка.
- Гул плавно меняет громкость за 0,18 с, шелест за 0,04 с. Ноль сначала затухает, затем останавливает player. Новый запрос отменяет прежний tween, выход из дерева освобождает tween. Быстрое листание не перезапускает звучащий шелест посередине семпла.

## Последствия

Ноль больше не требует синхронного stop: потребители ожидают короткого затухания. Сигнатуры громкости не меняются; предпочтения обновляются сразу. JSON, Journal, ShiftClock и сюжет прежние. Проверки: ui_polish_test, shift_clock_test, playthrough, book/presentation и check.ps1; графический обзор 1280×720/960×600.
