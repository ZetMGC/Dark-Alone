# CHAR-01: текстурированный TEST-посетитель

Владелец: второй участник + Codex. Ветка `codex/test-visitor-model`, база b64f51a. Прямое поручение 2026-10-28 после референсов Mouthwashing: один тестовый посетитель, без имени, биографии и нового guest_id.

## Проверка в игре

F5 из исходников этой ветки: D выбран по умолчанию. Escape → настройки → «[TEST] Лицо гостя» → **D · Текстурированный посетитель**. A/B/C возвращают прежние голову и тело. Выбор сохраняется при замене сцены только в текущем процессе.

Native-сцена: `scenes/characters/visitor_model.tscn`, генератор: `scripts/characters/visitor_model.gd`. Модель появляется при запуске F6, корень в редакторе до запуска пуст. Лицо направлено +Z, верх головы около +0.13 м, подошвы около -1.65 м. GuestArt поворачивает модель +90° Y, сохраняя прежнее направление гостя +X.

## Что сделано

Объёмная голова/нос/губы с фронтальной UV-проекцией, отдельные затылок/волосы/уши. Куртка с воротником, карманами и пуговицами; брюки, обувь, кисти с пальцами. Собственная кодовая ткань, оригинальная сгенерированная текстура лица, import-limit 256, nearest.

Skeleton3D: 15 костей, жёсткие сегменты BoneAttachment3D, явный reset_bone_poses после построения. Слабое дыхание, поворот головы, движение предплечья/кисти; DIALOGUE усиливает жест. Скрытая модель движения не обновляет; обычная пауза дерева их останавливает. Коллизии, позиция гостя, речь над головой, подача и прогресс прежние.

**Это первый упрощённый макет, не завершение DA-035.** Видимы отдельные сегменты плеч/кистей, бок головы и шов кожи требуют доводки. Нет мягкого скиннинга, моргания, липсинка, ходьбы, IK или анимации взятия стакана. Качество ткани и анатомии ещё ниже ручной модели из референсов. Финальный состав Q-04 не утверждён.

## Контракт

GuestArt сохраняет configure_controls(hud), set_test_appearance(id)->bool, get_test_appearance()->StringName. Добавлен `test_visitor`; неизвестный ID возвращает false без изменения. TestFace.get_appearance_ids() сохраняет только A/B/C и прежний контракт анатомии. GuestArt добавляет четвёртый пункт при configure, следит за NarrativeSession.mode_changed. Потребители: Main (прежний configure), faces_test (старые варианты), visitor_model_test (D/разговор/подача). Общие .tscn гостя/главной сцены не редактировались.

## Команды

```powershell
godot --headless --path . res://tests/visitor_model_test.tscn
godot --path . res://tests/visitor_model_test.tscn
godot --path . --script res://tools/capture_visitor.gd
```

Последняя команда пишет GPU-снимки `artifacts/visitor/studio_{0,65,150}.png`, face.png и test_visitor.glb. GLB — переносимый снимок текущей позы с материалами/структурой костей для дальнейшей работы в Blender; движения GDScript не запекаются. В headless выполняется только экспорт, без снимков. Native-сцена/код/текстура — исходник в Git, artifacts игнорируются. Скрипт visitor_model_test отдельно снимает bar.png.
