# ADR-0029 — выводы из слов и анимация книги

Уточнено владельцем в DA-067/[ADR-0030](0030-automatic-groups-stable-pages.md): круг появляется сам, вывод открывает точка; после двух выводов возможны авторские стрелки. Ручная обводка и прежняя имитация раскрытия/перерисовка preview ниже заменены. Формат выбранной интерпретации/evidence/условий NPC остаётся действующим.

Принято по прямому уточнению владельца 2026-10-28, DA-066. Заменяет ошибочную интерпретацию DA-065/ADR-0028 о свободном письме/перемещении личных блоков/редактировании рецептов.

## Механика

Свободного ввода в журнале нет. Автор задаёт группы слов и места на развороте; известные слова появляются рядом внутри своей группы, неизвестные не раскрываются. Игрок замкнутой обводкой выбирает достаточно слов одной группы и получает 2–4 авторских варианта вывода. Выбор записывается отдельно от найденных слов с ID варианта и списком сведений, на которых основан. Нет зелёной/красной оценки правильности. Один вывод на группу фиксируется без свободной перезаписи: это решение, которое дальше использует сценарий. Новые сведения не исправляют его автоматически.

Ответ диалога может иметь required_conclusions: список выбранных ID. Runner повторно проверяет условие при выборе, обе версии способны вести к разным узлам. Правильность и сюжетные последствия задаёт автор веток; UI/модель не вычисляют «истину». Демонстрация только TEST, основной intro не заменяется новым сюжетом. Рецепты — найденные авторские страницы, только чтение/листание; словарь сохраняет прежние пометки.

## Данные и совместимость

Необязательные reasoning_groups/journal_recipes в glossary JSON v1, валидация и снимки DialogueCatalog. JournalReasoning отделён от UI, опциональные conclusions в Journal progress. Восстановление проверяет выбранный вариант, порог, известность/принадлежность/уникальность доказательств и отсутствие повторного вывода до мутации. Верхний checkpoint и прежний content_hash не меняются от добавления групп/памяток, старые файлы читаются. ID групп/вариантов нельзя переопределять с другим смыслом без миграции. Поле notebook DA-065 читается/сохраняется как legacy-архив без игрового редактора и без автоматического превращения произвольного текста в факты.

## Анимации

Книга появляется с подъёмом/поворотом/оседанием и раскрытием обложки. Лист рисуется 32 изгибающимися полосами, с движущейся тенью, освещением и слабым просвечиванием оборота. На GPU поверхность несёт снимок реального текста; следующая словарная страница рисуется как предварительное изображение, не изменяя модель до конца анимации. Нет дублирования старого текста под листом. Полные времена: открыть 0.62 с, лист 0.58 с, закрыть 0.48 с; reduced 0.06 с, off мгновенно. Меню приостанавливает, закрытие отменяет незавершённый переход, сохранены serial-токены. Это 2.5D-представление, без новой зависимости/рук/полной физики бумаги.
