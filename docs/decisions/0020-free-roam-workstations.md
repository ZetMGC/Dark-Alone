# ADR-0020: Свободная ходьба и якоря рабочих мест

Дата: 2026-10-27. Статус: принято владельцем. Задача DA-052. Заменяет ограничение навигации ADR-0002, не отменяя исторические проверки графа.

## Контекст

Владелец предложил свободно перемещаться в пределах локации, оставив якоря для мест, где нужны фиксированный ракурс и действия мышью. Цель также убрать постоянную нижнюю панель направлений. В отдельном ответе подтверждены WASD/мышь → E/курсор → Escape/возврат.

## Решение

FreeRoamCamera с CharacterBody3D и коллизиями работает в баре и дома. Якорь больше не является средством дальнего перемещения: локальный вход проверяет радиус и преграду, фиксирует только камеру и сохраняет физическое место подхода. Модальные экраны и рабочее место блокируют ходьбу. Main/Home связывают локальные действия и Session; прогресс не переносится в камеру. UI показывает действия по месту, без направлений 1–4.

Прежний AnchorCamera остаётся базой для fade/обзора/настроек и самостоятельных контрактных тестов. Main имеет внутренний free_roam_enabled=false для прежних fixtures; игровой default=true, пользовательского переключателя нет. Новое поведение имеет отдельный сквозной тест исходников и Windows release-template.

## Последствия

Локации нужно проверять пешком и снабжать крупные препятствия коллизиями. Автосохранение не меняет формат: оно хранит границу смены, а не координаты. Персонажи/сюжет/рецепты этим решением не расширены. Скорость/радиус — первоначальные технические значения для плейтеста, не окончательный баланс. [FREE_ROAM](../FREE_ROAM.md), [CONTRACTS](../CONTRACTS.md).

Техническое основание физического движения: [Godot CharacterBody3D](https://docs.godotengine.org/en/stable/classes/class_characterbody3d.html), move_and_slide из physics_process. Фактическая совместимость проверяется на закреплённом Godot 4.7.2.
