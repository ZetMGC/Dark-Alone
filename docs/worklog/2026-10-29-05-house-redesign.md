# HOME-03: редизайн дома без перепланировки

## Запрос и владелец

Второй участник + Codex, 2026-10-29, ветка `codex/house-visual-redesign`, база `24d433d`. Пользователь просит переработать существующий дом, строго сохранив архитектуру, размеры и расположение основных объектов. Дом не заменён другим проектом. Ветка включает ранее локальные BAR-NIGHT-01/02, не публикует их автоматически.

## Результат

Добавлен отдельный декоративный слой после HOME-02: процедурные материалы, скруглённые края, оконная/дверная отделка, текстиль со складками, фасады кухни, бытовые предметы, сантехника, местный свет и общая приглушённая палитра. [Описание и снимки до/после](../HOUSE_REDESIGN.md), [ADR-0050](../decisions/0050-house-visual-layer.md).

Стены, комнаты, проёмы, мебель и их коллизии не двигались. До правок записан фактический snapshot; 272 статических узла совпали после редизайна. Динамическая капсула игрока исключена из архитектурного снимка; автоматически присвоенные цифровые суффиксы нормализуются. При скруглении AABB сравниваются с float-погрешностью. Никаких новых физических препятствий. Общие сцены не редактировались.

## Фактические проверки

- `tools/check.ps1 -Godot ./.tools/godot/Godot_v4.7.2-stable_win64_console.exe` — PASS, включая новый house_visual_test, старые игровые/домашние и полный цикл. Локальный лог `.tools/house-redesign-validation.log`.
- `house_layout_test.tscn` headless — 108 проверок, 0 ошибок. GPU/OpenGL с `--audio-driver Dummy` и снимками — 123 проверки, 0 ошибок: пешие маршруты, реальные лучи, двери, сидения, чайник/вода/радио/шторы/свет, отсутствие изменений прогресса.
- `house_visual_test.tscn` GPU — 272 исходных узла, 0 различий; декор без физических тел; ткань следует открытию/закрытию шторы; кухонный/настольный дополнительный свет и свечение подчиняются выключателям. Просмотрены вход, гостиная, кухня, кровать, письменный стол и санузел.
- После финальной коррекции источника под абажуром и увеличения сегментов округлых предметов повторён GPU visual/integrity, PASS. Общий gameplay-код не менялся.
- Дополнительно проверен профиль `--no-retro`: это существующая настройка игры, только внутри fixture, пользовательские предпочтения отключены. Документированные основные снимки используют стандартный ретро-профиль.
- `git diff --check` — PASS.

Команды из корня проекта (вместо `godot` — закреплённый executable):

```powershell
godot --headless --path . res://tests/house_visual_test.tscn
godot --headless --path . res://tests/parallel/home/house_layout_test.tscn
godot --path . --audio-driver Dummy res://tests/house_visual_test.tscn -- --capture-dir=artifacts/house_redesign/after
godot --path . --audio-driver Dummy res://tests/parallel/home/house_layout_test.tscn -- --capture-dir=artifacts/house_redesign/interaction
```

`--record-baseline` предназначен исключительно для первоначального неизменённого HOME-02. Существующий baseline не перезаписывается; не обновлять его ради прохождения проверки после перемещения стен/мебели.
