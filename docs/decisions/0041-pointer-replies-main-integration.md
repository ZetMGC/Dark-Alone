# ADR-0041 — ответы наведением без цифр

Принято по прямому поручению владельца 2026-10-28. У вариантов нет числовых префиксов, цифры и колесо не выполняют выбор. Наведение выделяет строку, E либо клик выполняют её; экранная подпись мыши не нужна. Курсор освобождается при доступности ответов, возвращается к управлению обзором при их скрытии. Во время набора текста клик также может продолжить речь, как E. Остаются проверки текущего диалога/доступности и запрет двойной активации.

Собственные старые ветки удалять только после включения их точных вершин в origin/main; использовать защиту от изменения refs. Ветки коллеги Henta14 сохраняются. Опубликованный alpha.4 не заменяется.
