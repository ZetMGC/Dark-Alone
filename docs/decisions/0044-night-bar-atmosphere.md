# ADR-0044: ночной бар

2026-10-29, принято по прямому поручению участника BAR-NIGHT-01. Область — ReferenceBar в reasoning_demo; планировка и старый graybox сохранены. Общий свет уменьшен вдвое, световые островки построены SpotLight3D с тенями, отдельные GuestFill/WorkbenchLight защищают читаемость механик. Холодные оконные пятна и слабый HallBounce сохраняют ориентацию в зале. Не используется SSAO, недоступный в текущем Compatibility-профиле.

Палитра тёмного ореха/грязной штукатурки/тусклой латуни, небольшие неинтерактивные следы пользования без нового канона. Мерцание только у одной дальней лампы: плавный провал ≤12% на 0.7 с в 23.7-секундном цикле. Оно не меняет гостевой/рабочий свет и останавливается вместе с деревом на паузе.

EnvironmentAudio.configure_night_bar()->void вызывается Main после готовности дочерних источников при reference_bar_enabled. Переназначает существующий Street на процедурный дождь, позиции Street/Furniture адаптирует к новому залу. Прежний гул служит вентиляцией; новый дублирующий гул не добавляется. Общие громкость/mute/контекст home/travel и редкое расписание скрипов сохранены. Никаких внешних аудиозаписей/лицензий/зависимостей. Потребители: Main, ReferenceBar, EnvironmentAudio, reference_bar_test; старый профиль контролируют environment_camera/presentation tests.
