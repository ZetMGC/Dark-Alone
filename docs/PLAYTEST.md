# Dark Alone — первый игровой цикл

Это прототип с TEST-текстами и первым художественным вариантом мрачного PS1-бара. Гость ещё не является каноническим персонажем.

## Запуск сборки Windows

Распаковать весь ZIP в отдельную папку и дважды нажать **Dark Alone.exe**. Файл **Dark Alone.pck** должен лежать рядом. Устанавливать Godot и открывать редактор не требуется. Начальная точка — вход в бар. Для выхода: Escape → «Выйти».

## Управление

| Действие | Клавиша |
| --- | --- |
| Перейти к точке | 1 — вход, 2 — за стойку, 3 — стол, 4 — угол; кнопки внизу |
| Осмотреться | ПКМ + мышь или стрелки |
| Вернуть взгляд | R |
| Взаимодействовать по прицелу | E |
| Разговор у стойки | T |
| Выбрать напиток | B |
| Дневник | J |
| Меню / назад из дневника и напитков | Escape |
| Выбрать ответ/кнопку | Мышь или Tab/Enter |

Переходы разрешены только между соседними точками. Время не течёт само: завершённый разговор и подача стоят по одному из двух делений. Отмена, чтение и перемещение бесплатны. Дневник/заказ не сохраняются после закрытия игры или новой смены.

## Проверочный проход — около 5 минут

В Escape доступны «Ретро-изображение» и громкость фонового звука. Сравнить вид с эффектом и без него, проверить чтение текста, обзор и переходы. На 0% звук полностью выключен. Настройки действуют до закрытия игры и сохраняются при новой смене. Отдельно сообщить, комфортен ли эффект и достаточно ли тихий фон.

1. Пройти 2 → 3 → 4 → 1 → 2. Игрок оказывается за стойкой, гость напротив в зале. Осмотреться, нажать R.
2. Нажать B и Escape: напиток не подан, остаток 2/2. Открыть T и отменить разговор: остаток также 2/2.
3. Снова T, выбрать «Спросить подробнее». В дневнике J должны появиться две TEST-записи. Escape возвращает к той же реплике. Завершить ветку и явно закончить разговор: остаток 1/2.
4. Нажать B, выбрать воду: появляется стакан, открываются итоги с двумя действиями и остатком 0/2. Перемещения больше не работают.
5. В итогах открыть дневник, вернуться, начать новую тестовую смену. Снова вход, время 2/2, дневник пуст, гость без напитка.
6. Второй проход: сначала подать «Напиток бара», затем в разговоре сразу выбрать «Закончить разговор» и закрыть конечную реплику. Итоги показывают другой напиток и одну запись дневника.
7. Из итогов проверить Escape → возврат и выход из игры.

Дополнительный маршрут DA-031: из итогов «Домой · закончить день» → анимированный TEST-переход → экран между сменами → J/дневник → возврат → «На работу · новая тестовая смена». Проверить Escape/паузу в пути и кнопку пропуска. Возврат на работу пока запускает новый тестовый цикл со сбросом записей, не продолжение сохранённой кампании. Полноценная книга и перенос знаний отдельно запланированы в JOURNAL_PLAN.

Два завершённых разговора тоже исчерпывают время; в итогах будет указано, что гость остался без напитка.

## Сообщить результат

Сохранить `build-manifest.json` или указать из него source_revision и source_dirty. Добавить версию Windows, видеокарту, размер окна, шаги воспроизведения, ожидаемое и фактическое поведение. Отдельно оценить удобство обзора, читаемость и расстановку. При ошибке запуска приложить лог `%APPDATA%/Godot/app_userdata/Dark Alone/logs/godot.log`, предварительно проверив личные данные.

Локальная проверка автора сборки не заменяет запуск коллегой. Не публиковать архив как финальную игру; условия распространения проекта отдельно не выбраны. Правовые уведомления движка — папка legal.
