# ADR-0023: Настройки отдельно от прогресса

Дата: 2026-10-27. Статус: принято для технического продолжения DA-057. Владелец выбрал отложить сюжет и продолжить механики; конкретная техническая задача выбрана агентом по известному ограничению настроек в памяти.

## Решение

Сохранять существующие предпочтения восприятия/окна в отдельный проверяемый JSON user://settings/preferences.json, вне checkpoint. PreferenceStore отвечает за версию/границы/атомарную замену, PreferenceController — за снимок, задержку записи и flush. Существующие модули испускают preferences_changed; Main связывает их после настройки UI.

Настройки не удаляются новым стартом, у них собственный явный сброс. Дисплей восстанавливается только при запуске; новая смена переносит память/конфигурацию хранилища. Размер/монитор ограничиваются доступным оборудованием; headless/встроенное окно пропускают дисплейную часть. Повреждённый файл не применяется частично и не блокирует игру, ошибка видна в меню. TEST-внешность и сюжет в предпочтения не входят.

## Последствия

Прогресс и настройки можно сбрасывать независимо. Модули не знают путей/версий файлов; no autoload, системы сюжетного прогресса прежние. Тесты обязаны отключать реальный Store либо подставлять каталог user://preference_tests/. Формат JSON v1 без миграций/облака/нескольких писателей; постоянная идентификация мониторов пока не реализована. [PLAYER_SETTINGS](../PLAYER_SETTINGS.md), [CONTRACTS](../CONTRACTS.md).
