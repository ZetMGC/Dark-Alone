# ADR-0051 — физика поверхности, жест крышки и исправление стакана

2026-10-29, DA-092. Четыре прямых требования владельца по скриншоту. Заменяет click-to-remove из ADR-0049/0050.

## Стакан

BackCounter масштабирован по Z до 0,6; предметы в ящике наследовали эту деформацию. World basis каждого переносимого supply теперь ортонормируется после создания; положение в мебели прежнее. Перенос не меняет физических пропорций. Прямоугольник под стаканом в _draw_cup рисовался до ветки прозрачного viewport: он оставлен только legacy-посуде. Alpha исходного рендера уже был корректен. Проверяется и alpha углов, и неизменность пикселя стола при композиции в настоящем UI.

## Поверхность и движение

TabletopMotion — детерминированная 2.5D-модель, без нового движка/зависимостей. Рабочая плоскость начинается на y=380 в логическом 1280×720, соответствует красной линии. Rect(20,380,1240,250) оставляет небольшой отступ от бокового/переднего края. Положение опоры на столе отделено от высоты над ним; upright-силуэт может выступать выше линии, опора всегда остаётся на поверхности.

При release используются последние реальные движения курсора (просроченная скорость затухает за 120 мс), масса стекла плюс остаток жидкости: 0,18 кг для маленькой бутылки, 0,32 кг для прежних плюс 0,001 кг/мл. Крышка 0,008 кг. Скорость/вращение ограничены; ускорение падения одинаково, отклик на жест зависит от массы. Подшаг 1/120 с; удар, небольшой отскок, трение и затухание. Резкий бросок или заметный наклон приводят к лежащему состоянию, осторожная постановка сохраняет вертикальное. Границы удерживают предметы на столе. Пустой alpha-margin маленькой бутылки исключён из физического размера.

Ни release, ни начало подъёма не меняют позу мгновенно. Клик по корпусу лежащей бутылки запускает подъём за 0,24 с; повторный drag выпрямляет её за 0,22 с, сохраняя последующее управление наклоном. Струя использует ту же позу горлышка. Пауза/потеря фокуса останавливают движение. Это приближённая физика 2D-предметов, не полная симуляция 3D rigid bodies; разрушения, столкновения бутылок друг с другом и автоматический пролив из лежащей бутылки не добавлены.

## Крышка

Нажатие на надетую крышку только начинает ожидание жеста; без перемещения она остаётся закрытой. После смещения на 8 логических пикселей крышка следует за курсором. При release сохраняется положение, затем действуют скорость, вращение, падение и трение на той же поверхности. Detached drag свободен; короткий клик по уже снятой крышке сохраняет быстрый возврат к бутылке. Перед закрытием движущаяся/лежащая бутылка плавно выпрямляется; финальное capped наступает после анимации. Блокировки скрытого UI/фокуса сохранены. Программный toggle_bottle_cap остаётся для совместимости тестов/команд, на клик надетой крышки не вызывается.

## Тени и API

TabletopMotion.shadow рисует мягкую многослойную контактную тень: форма зависит от предмета/наклона, размытие и плотность от высоты. Бутылка лёжа даёт длинную тень, посуда лёгкую овальную, ложка узкую, лёд и крышка компактные. Тени работают и во время drag/полёта. Stored cups тоже учитываются.

DrinkWorkbench.bottle_motion, advance_tabletop(delta), is_bottle_lying(id), stand_bottle(id); advance_motion теперь включает шаг физики/выпрямления, _bottle_transform единообразен для руки/поверхности. BottleCapItem.take_from_bottle/press_pointer/drag_pointer/release_pointer и motion. Потребители: UI hit/pour/shadows, WorkbenchSupplies, small_bottle/workbench/tabletop tests; source и Windows runners. Старые тесты налива изолируют fixture от предыдущего броска и ожидают завершения подъёма. Runtime состояния в текущей смене; checkpoint не расширяется.
