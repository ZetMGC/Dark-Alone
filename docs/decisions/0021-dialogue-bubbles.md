# ADR-0021: Пузырьки речи, ответы взглядом и важные слова

Дата: 2026-10-27. Статус: принято по прямому запросу владельца. Задача DA-053. Уточняет UI/обзор ADR-0004 и исключение из фиксации камеры ADR-0020.

## Решение

Речь NPC рисовать как экранный пузырёк, спроецированный над его головой; при выходе говорящего из поля зрения переносить в угол с направлением. Типографский набор приостанавливать меню/дневником; при отвороте продолжать. Ответы показывать только после набора и при взгляде на NPC: цифры выбирают сразу, колесо выбирает/F подтверждает. Первое F при наборе только раскрывает текст. Последняя реплика требует явного завершения. Во время разговора разрешить обзор на месте, тело оставить заблокированным.

Оформление — новый DialogueBubblePanel поверх прежнего DialoguePanel/Runner/Session, с самостоятельным сквозным тестом. Старое представление сохраняется для legacy fixtures. Важные слова задаются парными ** в node.text, без исполнения сторонней разметки. Новую механику фиксации выделений в дневник не добавлять: прежние эффекты grant_term независимы.

## Совместимость и последствия

Парные ** исключаются из отпечатка текстов checkpoint; чистое оформление сохраняет точный старый hash, содержательные изменения сохраняют прежний строгий отказ. Схемы JSON v1 не расширяются. Обзор управляется FreeRoamCamera.set_dialogue_look, UI-проверка взгляда не переносится в Runner. Для нескольких NPC потребуется явно привязывать текущего говорящего; одновременные разговоры не реализуются.

38 символов/с, угол 20° и размеры UI — исходные параметры для человеческого плейтеста, не окончательный баланс/доступность. Системные шрифты не распространяются. Подробности — [DIALOGUE_BUBBLES](../DIALOGUE_BUBBLES.md), [CONTRACTS](../CONTRACTS.md). Техническая справка: [Godot RichTextLabel](https://docs.godotengine.org/en/stable/classes/class_richtextlabel.html); совместимость проверяется на закреплённом Godot 4.7.2.
