# ADR-0035: Открытый шейкер, крышка и процеживание

Статус: принято, 2026-10-28, прямое поручение владельца.

DA-073: трёхсоставной шейкер, open/sealed/straining. Залив/лёд/ложка только open; shake только sealed; выход через стрейнер только straining (крышка остаётся, колпачок снят). Налив на крышку расходуется в пролив, состав сосуда не меняет. Кнопки большой крышки и колпачка работают когда предметы стоят. Drop стакана больше не мгновенный transfer: налив только общей видимой струёй. Металл/горловина/съёмные детали процедурные, в текущем стиле 2D-верстака. Состояние крышки — UI/runtime, не sealed итоговой порции в DrinkPreparation. Предыдущие mix/transfer и состав/лёд/расход сохраняются, нового save нет. [Контракт](../parallel/bar/CONTRACTS.md).
