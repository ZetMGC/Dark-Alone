# 2026-10-28: DA-076 — тихий интерфейс

Исполнитель: агент UI. Ветка codex/da076-quiet-interface, база 6f26b75. Область общих сцен занята одним редактором этой задачи, по завершении освобождена.

## Выполнено

Нижние постоянные инструкции скрыты в баре, доме, дневнике, диалоге и приготовлении. Вместо + общий прицел-точка, который плавно раскрывается в маленькое кольцо только у доступной цели; недоступная цель не даёт кольцо. Активация объектов и ввод не менялись.

Общий NoticeBubble: 4.5 с, плавное появление/затухание, подавление повторов, без перехвата мыши. Контекстные потребители — HUD, дом, дневник, диалоги, верстак. Во время паузы HUD скрывает свою подсказку. Сохранения не менялись; повторный запуск сбрасывает факт показа.

Карточка бутылки рядом с курсором показывает название, остаток и крепость только при наведении на стоящую бутылку. При захвате любой тары, промахе, потере фокуса или закрытом верстаке её нет. Координаты учитывают масштаб поверхности, карточка ограничена краями. Прежнее название удерживаемой бутылки и нижние инструкции не рисуются.

Пауза ограничена шириной 360, настройки 560 логических единиц. Основные кнопки 300×40, центрируются; высота прокрутки настроек зависит от высоты окна, ширина не растёт с ультрашироким экраном. Конкретные размеры — решение для текущей типографики, не утверждение о едином стандарте всех игр.
