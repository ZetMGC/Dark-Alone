# ADR-0045: визуальный слой поверх неизменного HOME-02

Дата: 2026-10-29. Accepted по прямому поручению второго участника HOME-03.

Дом редизайним на существующей геометрии. `HouseInterior.build(home)` сначала создаёт ровно прежнюю основу, коллизии и действия; затем добавляет `VisualDressing` (`scripts/home/house_dressing.gd`) и вызывает его локальный `build(source: Node3D)->void`. Другие потребители этот метод не вызывают. Общие `.tscn`, HomeState, взаимодействия/Session, save и настройки не меняются.

Слой заменяет только материалы/визуальные меши, не меняя transform и AABB исходных MeshInstance3D и физических форм. Для ткани/сантехники/лампы возможны отдельные декоративные меши при скрытом исходном визуальном блоке; исходный Body остаётся целью луча. Новые детали не добавляют CollisionObject3D. Накладки шкафных дверей — дочерние узлы прежних петель; шторы синхронизируются с прежней позицией и размером. Новые источники следуют видимости прежних светильников; рассеиватели гаснут вместе с ними.

Процедурный spatial-шейдер — локальная метрическая проекция, фактура/шероховатость/микрорельеф, без зависимости от UV, новых изображений или внешних пакетов. Параметры: tint, kind (0–8), roughness_value, relief. Environment назначается только домашней камере, поэтому бар и глобальный ретро-профиль не перекрашиваются. Источники остаются штатными Omni/Spot с тенями Compatibility; GI/настоящие отражения не добавлены.

Защита требования пользователя: неизменяемый снимок из исходного `24d433d` в tests/fixtures/house_layout_baseline.json и house_visual_test. Проверка включена в check.ps1. Сравниваются 272 узла, декор без новых коллизий, движение тканевой визуализации и выключатели. Старые house_layout/home_target/legacy и общий цикл проверяют существующие механики. Эстетическое качество проверяется кадрами GPU и отзывом участника, headless его не доказывает.

Публичный API HOME-02 и список его потребителей прежние. Новая внутренняя связь: только HouseInterior → VisualDressing; тесты дополнительно читают этот дочерний узел. Декор не утверждает новый канон и не становится предметами инвентаря.
