# ADR-0029: рост игрока, запястья и точки речи

Уточнение CHAR-05 после новых скриншотов: по просьбе «чутка увелич» размер поднят на 5% от CHAR-04 до MODEL_SCALE=1.1004 (~1.89 м). Описанный ниже 1.048 — исторический этап. Правила опоры на пол, размеров капсул и точек речи остаются действующими; API не меняется.

2026-10-28, принято по прямым уточнениям второго участника: после чернового увеличения 1.3 — сделать ростом с игрока; затем исправить руку по скриншоту.

Итоговый MODEL_SCALE=1.048 от геометрии CHAR-03, с опорой на FLOOR_Y=-1.65. Рост около 1.80 м, глаза около 1.65 м соответствуют капсуле/камере FreeRoamCamera. Черновой масштаб 1.3 заменён.

Ладонь/пальцы строятся в ортонормированном базисе предплечья в rest-пространстве. Поворот HandL на 0.95 рад удалён, остались малые движения. Сечения рукавов перпендикулярны своей оси, пальцы расслаблены; правая кисть подстроена под стойку.

ServiceGuest.configure_body_scale(multiplier)->bool масштабирует уникальные CapsuleShape3D цели/ходьбы от пола, отклоняет неконечный/неположительный ввод. Исходные размеры/позиции запоминаются один раз, масштаб не накапливается. GuestArt вызывает его при выборе D/A/B/C. Положение гостя/стакан не масштабируются.

ServiceGuest/GuestArt добавляют get_dialogue_head_position()/get_dialogue_face_position()->Vector3. DialogueBubblePanel вызывает их опционально через has_method; обычный Node3D сохраняет прежние смещения. Направление взгляда считается к face.

Потребители/проверки: GuestArt, ServiceGuest, DialogueBubblePanel, visitor_model_test, capture_visitor; прежние faces/dialogue_bubble/world_target/free_roam проверены общим check. Main/общие .tscn/Session/save-схема прежние.
