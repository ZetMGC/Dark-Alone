# ADR-0030 — автоматические группы и стабильные страницы

Принято по уточнению владельца 2026-10-28, DA-067. Заменяет ручную обводку и способ анимации DA-066/ADR-0029; модель выбранных версий/evidence и условия NPC сохраняются.

Группа автоматически получает круг, когда известных слов достаточно по minimum_terms. Рядом появляется маленькая точка с увеличенной областью клика; она открывает авторские варианты вывода. Рисования мышью нет. После выбора точка исчезает, остаются круг и текст версии. Связь двух групп задаётся автором и появляется стрелкой только после выводов по обеим группам; optional required_conclusions уточняет зависимость от конкретных версий. Стрелка не является зелёной отметкой правильности. Отдельное runtime-состояние/поле сохранения для кругов/стрелок не нужно: они выводятся из знаний и выбранных версий.

Добавлен optional glossary.reasoning_links, ссылки/условия/дубли/одинаковый разворот валидируются каталогом. Старые пакеты/сохранения читаются, hash метаданные не меняют. Конкретные связи мира не придумываются: shipped-контент пока одна TEST-группа, связанные группы проверяются тестовой fixture.

Мигание было вызвано изменением ширины бумаги/пороговой прозрачности текста при открытии, ручным переотрисовыванием preview другим шрифтом/геометрией и удалением кадра листа до завершения реальной пагинации. Теперь книга поднимается цельным уже раскрытым разворотом; ширина страниц и прозрачность букв постоянны. Прежняя имитация распахивания обложки убрана. Full/reduced/off и закрытие сохранены.

Для GPU-перелистывания используются два изображения от одного и того же JournalPanel: текущий разворот и целевой, отрисованный в отдельном SubViewport на изолированной копии Journal. Неподвижные половины и обе стороны изогнутого листа берутся из этих изображений. Реальные знания/курсор не меняются до завершения анимации. После commit целевой кадр удерживается до окончания пагинации/раскладки; затем передаётся живому UI. Так типографика/пометки/фактура не подменяются в последнем кадре. Снимки/временный viewport освобождаются, ничего не сериализуется. Меню приостанавливает Tween/подготовку; serial защищает отмену.
