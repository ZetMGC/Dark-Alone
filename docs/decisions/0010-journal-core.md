# ADR-0010: Записи дневника и знания между сменами

Дата: 2026-10-26. Статус: Accepted для DA-033. Книжное оформление остаётся DA-034.

## Решение и границы

Journal сохраняет прежние API терминов и дополняет записи метаданными: устойчивый entry_id=`term:<term_id>`, порядок получения, source (dialogue_id/node_id/speaker/shift), read и bookmarked. Источник задаёт DialogueRunner при grant_term; старый add_term(id) без источника совместим и показывает «Источник не указан». Контекст — идентификаторы и подписанный speaker из принятого контента, не автоматический сюжетный вывод/цитата. JSON v1 не меняется.

Один термин становится одной записью, повтор не меняет первый источник и отметки. Чтение/выбор и закладка — явные команды Journal через NarrativeSession, не побочный эффект render. Неизвестные ID/невалидные источники и вложенные изменения отклоняются. Поиск/фильтры «Все/Новые/Закладки» возвращают копии, выбранная запись хранится по term_id, не номеру страницы. Закладки — флаг записи; личные заметки, досье и связи не входят.

Обычная следующая смена через дом переносит тот же Journal и увеличивает номер смены; часы, заказ, Runner и граф создаются заново. Для передачи при reload_current_scene используется одноразовая мета-запись SceneTree с Journal, номером и точным scene_file_path; новая Main потребляет её только для того же пути, проверяет совместимость каталога и удаляет запись. Это короткая передача объекта в памяти, не глобальная шина, autoload или файл сохранения. Ошибка запуска не должна молча создавать пустой дневник. При ошибке запроса reload передача удаляется. Прямой тестовый reset не создаёт передачу и очищает знания. Закрытие процесса всё теряет: Q-06 не решён.

Сессия получает необязательные shared_journal и shift_number в конце configure. Runner получает необязательный shift_number. configure_shift теперь допускает настроенный непустой дневник до начала новых действий. Совместимость shared_journal проверяется по полным определениям словаря, без скрытого обновления принятого снимка.

## Последствия и потребители

Main, NarrativeSession, DialogueRunner, JournalPanel/HUD и тесты обновляются вместе с CONTRACTS. UI пока рабочий индекс/детали, без обещания физической книги или анимации листания. DA-034 заменит представление на этой модели. Сейчас единственный эффект JSON v1 — grant_term; будущие другие эффекты требуют отдельного решения о межсменном журнале их применения. Runtime-прогресс не пишется в исходники/сцены/чат или на диск.
