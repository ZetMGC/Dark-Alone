# Основание концепта

2026-10-28: по прямому запросу второго участника сохранён конкретный [референс персонажей Mouthwashing](mouthwashing-character-reference.png). Подробный разбор/назначение — [CHARACTER_REFERENCE](../CHARACTER_REFERENCE.md). Только документационный художественный ориентир, не игровой ассет.

Использованы только материалы, относящиеся к игре:

1. Чат **«Создание игры»**, идентификатор `691b4d25-7388-8331-bffc-14c0c96e4329`.
2. Исходная доска идей из вложения к этому чату — [concept-board.png](concept-board.png). Локальная копия включена для коллег, у которых нет доступа к чату.
3. Прямая формулировка автора в последнем обсуждении: «Хотим игру от первого лица с перемещением камеры по якорям».
4. Текущая задача: Godot, базовый репозиторий, начальный план и подробная документация для продолжения коллегами и агентами.

Некоторые последние ответы ассистента в старом чате представлены ссылкой на содержимое без доступного текста. Их формулировки здесь не восстановлены и не выданы за требования. Концепт основан на читаемых сообщениях и просмотренной доске.

Старая дискуссия включает Unreal-специфичные советы. Из неё перенесены продуктовые идеи и разделение систем; типы Blueprint и архитектура Unreal не используются.

Технические ссылки, проверенные 2026-10-26:

- [Архив Godot 4.7.2 Standard](https://godotengine.org/download/archive/4.7.2-stable/) — закреплённая версия проекта.
- [Командная строка Godot](https://docs.godotengine.org/en/stable/tutorials/editor/command_line_tutorial.html) — импорт, headless и запуск скриптов. Ссылка stable может обновляться; при расхождении ориентироваться на `--help` закреплённой версии.
