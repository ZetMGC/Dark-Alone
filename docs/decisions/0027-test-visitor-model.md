# ADR-0027: один текстурированный TEST-посетитель

Реализация жёсткого макета ниже заменена CHAR-02 / ADR-0028; внешний выбор D/A/B/C и границы TEST остаются.

2026-10-28. Принято прямым поручением участника после новых референсов Mouthwashing. Возобновлён пробный художественный проход ADR-0015; естественные пропорции остаются целью, финальная внешность/персонажи Q-04 не утверждены.

Собственная геометрия Godot, оригинальная текстура лица через встроенный imagegen, кодовая ткань и простой Skeleton3D. Новые программы/зависимости не устанавливаются. D добавлен в прежний TEST-переключатель, A/B/C сохраняются. Меняется только видимый Body; идентификаторы, коллизии и игровые системы прежние.

Жёсткие сегменты и фронтальная UV-проекция — ограничение макета. Следующий проход требует боковых текстур, мягкого скиннинга и ручной доводки. Этот результат не закрывает DA-035. Контракт/команды — [CHAR-01](../CHARACTER_PROTOTYPE.md).
