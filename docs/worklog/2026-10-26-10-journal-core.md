# 2026-10-26: DA-033 — основные механики дневника

Исполнитель: агент DA-033. Ветка `codex/da033-journal-core`, база `6d3a409`. Начальное дерево чистое; fetch подтвердил origin/main=`07bed83`. Текущая ветка включает предыдущие этапы. Общие сцены Journal/Commute/Summary редактировал один агент, иных назначенных владельцев в локальном BACKLOG нет.

## Выполнено

Journal расширен устойчивым entry_id, порядком, первым источником dialogue/node/speaker/shift, read/bookmarked и выбранным term_id. Прежние методы/поля определений и однопараметрический add_term совместимы. Источник передаёт Runner из принятого узла, JSON v1 не менялся. Повтор не переписывает источник/отметки. Неизвестные ID/разделы, невалидный контекст, вложенные команды отклоняются; getters возвращают копии.

JournalPanel теперь рабочий индекс/детали: поиск, все/новые/закладки, переход по результатам, метки, источник и выбор закладки. render не меняет прогресс, явные команды идут через Session. Только показанная запись становится прочитанной. Выбранная запись может оставаться открытой вне фильтра с явной подписью — чтение не обрывается, если запись исчезла из «Новых». При фокусе поиска J/T/B не запускают игровые действия. Чтение бесплатно и сохраняет реплику/режим возврата. Книга/листание пока не реализованы.

Обычный путь домой/на работу передаёт тот же Journal через одноразовые метаданные SceneTree, привязанные к сцене. Новая Session принимает только совместимый словарь, повышает номер смены, обновляет часы/заказ/Runner. Передача потребляется и не остаётся после возврата. Прямой reset переименован в «Сбросить тестовый прогресс» и очищает знания/номер. Дисковых сохранений нет.
