# ADR-0005: Первый гость и подача напитка

Дата: 2026-10-26. Статус: Accepted для DA-022.

## Основание и границы

После слияния DA-021 владелец разрешил продолжить план и уточнил художественную цель PS1 / современная подача в духе Mouthwashing. На вопрос Q-01 выбран короткий список напитков. В этом этапе два явно тестовых варианта, один гость, одно обслуживание за сессию; деньги, рецепты, физическое приготовление, доверие, канон и время не добавляются.

## Решение

Отдельная модель GuestService проверяет меню до конфигурации, хранит выбранный напиток и состояние served. Подача известного ID допустима один раз; неизвестный ID, повтор и вложенный запрос из сигнала отклоняются. Завершение имеет стабильный ключ `service:<guest_id>` в пределах текущей сессии, который сможет использовать будущий координатор времени. Новый экземпляр модели начинает новое обслуживание.

Меню — небольшой экспортируемый массив записей id/title/description в Main, который копируется в модель. Это технические настройки одного гостя, не расширение JSON v1. Новый тип эффекта в DialogueRunner не нужен: подача — самостоятельная команда сервиса. Если позже потребуется сценарная схема меню/заказов, она принимается отдельно.

ServicePanel — модальный экран; B или кнопка «Обслужить» открывают его только у стойки вне разговора и fade. Escape или «Назад» закрывают без подачи. Выбор «Подать» завершает обслуживание и возвращает исследование. Меню паузы сохраняет экран сервиса; после возобновления можно продолжить выбор. Пока сервис открыт, навигация, обзор, разговор и дневник не исполняются.

Техническую сферу разговора в Main заменяет сцена TEST-гостя на том же общем интерфейсе Interactable3D/DialogueTrigger. Старое имя узла DialogueTrigger сохраняется для потребителей. Его тело видно постоянно, маркер — только при доступном взаимодействии. После подачи на стойке виден стакан и читаемый статус с выбранным напитком. Разговор до и после подачи использует прежние TEST-данные, без неподтверждённых сюжетных последствий.

## Визуальная совместимость

Гость — low-poly-заготовка из простых форм, с приглушённым цветовым акцентом. Финальные лицо, текстуры и PS1-обработка относятся к художественному проходу DA-030; подтверждённое направление записано в VISUAL_DIRECTION. Структура позволяет заменить внешность без изменения модели обслуживания и камеры.
