[Текущий результат](CHARACTER_PROTOTYPE.md), [протокол](worklog/2026-10-28-04-reference-model-pass.md). Это продолжение существующей задачи, финальные личности/канон не определяет.

**Конкретный референс для будущих моделей, сохранён по прямому запросу участника 2026-10-28:** [картинка, подробный разбор и критерии](CHARACTER_REFERENCE.md). При доработке персонажей читать этот документ и сравнивать с самим кадром. Ключ: индивидуальные силуэты/пропорции/позы, выразительные стилизованные лица, объёмные пряди, связная форма одежды и согласованная детализация всех частей. Достигнутые изменения и ограничения описаны в CHARACTER_PROTOTYPE; точное сходство/идеальное качество не объявляются автоматически по факту PASS тестов. Финальные личности/канон прежние.

## Утверждено

**Персонажи должны быть реалистичными.** Ориентир владельца — *No, I'm not a Human* (в чате «im not a human»); допустим немного меньший реализм при близком ощущении стилистики. Рабочая ссылка для сверки: [официальная страница игры](https://store.steampowered.com/app/3180070/No_Im_not_a_Human/). Это ссылка на визуальный ориентир, не разрешение использовать чужие модели/текстуры и не спецификация движка референса.

Уточнение относится ко всему персонажу, не только различимости лица: убедительная анатомия головы/тела, естественные пропорции глаз/носа/рта, правдоподобные кожа/волосы/одежда и согласованный свет. Допустима сдержанная стилизация; выраженно геометрические клиновидные носы, плоские маски и блоковые тела нынешних моделей не считать утверждённым финальным стилем.

Общее направление мрачного мира PS1 в современной подаче / Mouthwashing сохраняется. Оно не требует оставлять персонажей предельно угловатыми и не оправдывает потерю читаемости. Целевую степень реализма конкретно проверять на изображении и в игре, не выводить её из количества полигонов.

## Что оставляем сейчас

По прямому решению владельца лица TEST A/B/C **оставить на ближайшее время**. Это допустимые временные модели для проверки механик, а не одобрение художественной цели. В текущем выпуске не переделывать их снова, не менять персонажей/сюжет/guest_id по внешности. DA-035 возвращена в todo для будущего реалистичного прохода; финальный состав и portrait/character привязки требуют Q-04. Дневник DA-038 остаётся отдельным вопросом, ожидающим концепт владельца.

## Будущий проход — предложение способа работы

Сначала один качественный тестовый персонаж: согласовать несколько конкретных ракурсов/референсов, подготовить более подробную анатомию и собственные/лицензированные текстуры кожи/глаз/волос/одежды, настроить материалы/свет в Godot. Сравнить в нейтральном освещении и у стойки при adaptive/native, затем получить оценку владельца до распространения на весь состав. Текущая процедурная геометрия не заменяет этот художественный проход.

Агент может реализовать/интегрировать геометрию, материалы, текстуры, глаза, волосы, освещение и инструменты сравнения, вести последовательные итерации по оценке. Точное визуальное качество не гарантируется одним автоматическим проходом: потребуются проверяемые ассеты и художественная полировка. Выбор внешнего 3D-инструмента/крупной зависимости — отдельное решение; этой задачей он не установлен. Канон/финальные личности не придумывать.

Решение — ADR-0015. При продолжении DA-035 читать этот документ перед старым TEST_FACES; старые снимки/описания сохраняются как история технического прототипа.
