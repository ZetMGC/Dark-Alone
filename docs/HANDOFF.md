## Продолжить работу за одну сессию

1. Начать с README и STATUS. Проверить ветку, `git status`, последние коммиты и актуальность копии относительно общего сервера, если он уже есть.
2. Прочитать CONCEPT: утверждённое, предложенное и нерешённое отделены. Для технической работы — ARCHITECTURE, CONTRACTS и ADR.
3. Найти последнюю запись `docs/worklog/`. Выбрать свободную задачу BACKLOG, проверить зависимости. Не начинать с первого случайного TODO в коде.
4. Запустить проверки основы. Если они не проходят до изменения, записать исходную проблему.
5. Сделать ограниченную задачу, проверить её критерии, обновить документы и оставить handoff по шаблону.
