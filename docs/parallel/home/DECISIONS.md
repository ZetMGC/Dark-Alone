# DA-062: решения домашней дорожки

2026-10-27. Применяем существующий register_surface к дому без изменения общих систем. Это локальное продолжение ADR-0020/0024: реальные коллизии служат целями, плавающие сферы остаются только в legacy. Для управления при ходьбе try_focus больше не вызывается: он мог выбрать точку без попадания в нужный предмет.

Сохраняем четыре существующих объекта и их ракурсы/координаты. Единственное уточнение free-roam ракурса: домашний вход развёрнут к двери (yaw 180° вместо взгляда внутрь комнаты), иначе поверхность двери за спиной недоступна курсору. Геометрия/тело/граф legacy не меняются. Расширение планировки и новые бытовые взаимодействия из обсуждения в чате — предложения для следующей задачи, в DA-062 не реализованы.

Публичные стабильные API/формат сохранений не расширялись. Общие документы и runner оставлены координатору согласно PARALLEL_WORK; профильный runner отдельный.
