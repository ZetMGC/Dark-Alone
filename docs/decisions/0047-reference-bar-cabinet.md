# ADR-0047 — шкаф за стойкой

Принято 2026-10-29, DA-088. По прямому запросу владельца меняется именно мебель шкафа по отмеченной области присланного изображения. Тёмный деревянный каркас с открытыми секциями и широким карнизом выполняется геометрией/существующим worn shader. Декоративные бутылки исключены, семь предметов WorkbenchSupplies занимают два уровня; пустые секции остаются свободными. Свободную пользовательскую расстановку владелец обозначил дальнейшей механикой; здесь сохраняются текущие перенос/возврат/stock.
