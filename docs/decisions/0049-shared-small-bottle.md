# ADR-0049: общая модель бутылки и крышка

2026-10-29, DA-090. Прямой запрос владельца после утверждения концепта.

Восьмая бутылка test_stvor, вымышленный «Северный створ», 250 мл. Состав 40% и вкусовые свойства — TEST-настройки, не каноническая рецептура. Остальные семь компонентов не меняются.

SmallBottleVisual создаёт плоский скруглённый корпус, плечики, открытое резьбовое горлышко, отдельную металлическую крышку и этикетку. Один генератор используется на полке/столе/в руке и в прозрачных SubViewport для 2D. Отдельный вид крышки также из той же геометрии. Рендер обновляется при создании/изменении состояния, не каждый кадр. Этикетка — авторский SVG; кириллица Label3D, поскольку импорт SVG в Godot не поддерживает text.

DrinkWorkbench хранит runtime-состояние крышки. ЛКМ по крышке снимает её, ЛКМ по снятой рядом надевает. Во время drag, без фокуса, в скрытом UI или без предмета переключение запрещено. Клик не начинает drag. Закрытая бутылка не даёт струю и не расходует запас. Крышка связана с бутылкой: в мире скрывается, в 2D лежит рядом; отдельного слота нет. Перенос/возврат сохраняют состояние до конца текущей смены. Checkpoint-схема прежняя.

API: DrinkBottleStock.configure(catalog, default_capacity, capacities={}) проверяет overrides до изменения запаса; прежние вызовы совместимы. DrinkWorkbench.is_bottle_capped(id), get_bottle_cap_rect(), toggle_bottle_cap(id), сигнал bottle_cap_changed(id,capped). Rect в логических координатах. WorkbenchSupplies синхронизирует мировой узел по сигналу. SmallBottleVisual.make_preview(parent,cap_only=false) создаёт изолированный рендер.

Потребители: DrinkWorkbench, WorkbenchSupplies, small_bottle_test. Обновлены ожидания supplies/cabinet, check.ps1 и Windows Validation (--small-bottle-check). Остальные бутылки/посуда/инструменты сохраняют модели, массовая замена — следующий художественный проход.
