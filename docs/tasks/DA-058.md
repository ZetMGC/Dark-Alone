# DA-058: Стойка и посетитель как цели взаимодействия

Статус in_progress. Владелец агент DA-058. Ветка codex/da058-world-interaction-targets, база 53f3064 (включает DA-057).

Запрос владельца: нормальные якоря, наводиться на стойку для её открытия, на посетителя для диалога. E остаётся подтверждением прежнего управления; одно наведение показывает подсказку. Нельзя запускать действия издалека/сквозь препятствие. Разговор рядом с гостем допускается без рабочего якоря, тело остаётся заблокированным на время речи. На занятом месте курсор выбирает NPC/поверхность; стойка даёт прежнее меню напитков.

Объём: явная привязка физических поверхностей к Interactable3D, свежий луч при E, отдельная цель стойки/большая область NPC; убрать барные маркеры в игровом режиме. Дом/сюжет/арт/баланс/сохранения не расширять. Main/HUD/guest-сцену редактирует один агент; рабочая копия чистая, иных владельцев в BACKLOG нет.

Приёмка: наводиться на дерево/корпус стойки и тело/голову гостя, E различает цели; клиентская сторона даёт объяснение подхода к рабочему месту; посетитель рядом говорит без телепорта, дальний/закрытый недоступен; курсор работает у стойки, скрытые/устаревшие цели не срабатывают; прежние циклы/меню/дневник/настройки проходят проверки, просмотр исходников/GPU/экспорта, документация обновлена.
