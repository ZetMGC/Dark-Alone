# ADR-0017: Тихое окружение и регулируемая камера

Дата: 2026-10-26. Статус: Accepted для DA-048, по прямому поручению пользователя. Номер 0016 не переиспользуется: решение отменённой полировки осталось в истории Git.

## Решение

Сохранить исправленный гул вентиляции DA-047. Добавить независимую EnvironmentAudio со своими пространственными источниками: улица у окна и редкий скрип у стола. Оба звука синтезируются собственным кодом, внешних записей/зависимостей нет. Улица — тихая 12-секундная петля с периодическим фильтрованным шумом и дополнительным граничным отсчётом; скрип — 0,8 с с нулевой огибающей на концах и небольшим изменением тона. Первый скрип через 12–24 с, последующие через 18–38 с только в исследовании. В модальных экранах таймер стоит; при потере фокуса новые события не планируются. Общий ползунок фонового звука управляет всеми тремя слоями, ноль останавливает их. Новые источники выключены в travel/home, вложенные меню/дневник сохраняют этот контекст. Прежний непространственный гул не меняется.

В меню добавить скорость обзора 50–200% (мышь и стрелки вместе), полную длительность fade 0,2–1,0 с и возврат исходных значений. Исходные 100% и 0,5 с сохранены до человеческой оценки. Коэффициенты: mouse=0,003*скорость, keyboard=1,5*скорость; black_hold=0,06 с, каждая сторона fade=(полная длительность−0,06)/2. Новое значение влияет на следующий переход, не перестраивает текущий Tween. Предпочтения только в памяти процесса, как настройки изображения/звука; дисковых сохранений нет.

## Проверка и последствия

EnvironmentAudio не меняет прогресс/диалоги/время. Main связывает только контекст и настройки камеры, общая главная сцена/бар не редактируются. Новые источники расположены по текущей геометрии; при переносе окна/мебели обновлять environment_audio.tscn. Контракты — CONTRACTS. Автоматические проверки реального микшера, диапазонов, ввода/переходов/новой сцены; графические снимки меню в 1280×720 и 960×600. Субъективные громкость/тембр/комфорт оценивает команда; процедурный звук остаётся первым вариантом.
