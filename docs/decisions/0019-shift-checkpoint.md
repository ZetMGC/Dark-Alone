# ADR-0019: Автосохранение начала смены

Дата: 2026-10-27. Статус: принято, Q-06 выбрано владельцем. Задача DA-032.

## Контекст

Journal и HomeState уже переносятся между сменами в памяти. Владелец выбрал автосохранение между сменами. Сохранение незавершённых разговоров и анимаций потребовало бы отдельного контракта.

## Решение

При успешном старте следующей смены после возвращения из дома сохранять номер, Journal и HomeState в версионированный JSON в user://. Загрузка автоматически создаёт свежие часы, заказ и Runner. Полная проверка создаёт новые модели; файл ограничен 1 МиБ и связан с отпечатком контента. Временная запись с заменой, предыдущая исправная копия, объяснение отказа и явный подтверждаемый новый старт описаны в [SAVES](../SAVES.md).

## Последствия

Можно продолжить после перезапуска без сериализации дерева сцены. Прогресс внутри смены откатывается к её началу. Изменение каталога требует будущей миграции либо нового старта. Настройки не сохраняются. Тестовые сцены изолированы от пользовательского файла. Потребители: Main, Journal, HomeState, HUD, тесты и команды снимков; публичные интерфейсы — [CONTRACTS](../CONTRACTS.md).
