# ADR-0028: цельная геометрия и UV для посетителя

Дата: 2026-10-28. Принято прямым поручением второго участника после оценки CHAR-01: приблизить посетителя к предоставленным референсам Mouthwashing, исправить тело/одежду/бок головы/позу.

Отдельные жёсткие примитивы и фронтальная маска заменены одним skinned ArrayMesh с тремя материалами. Существующие 15 костей сохранены; Skin содержит обратные global-rest матрицы, локти/колени/талия — смешанные веса. Добавлены замкнутый череп с непрерывной UV, текстурные складки/швы, небольшой перенос веса и поза опоры на текущую стойку.

Три оригинальных атласа через встроенный imagegen: голова, тот же UV с закрытыми глазами и одежда. Импорт 512px, nearest/mipmaps. Моргание — переключение двух кадров, без поверхностей-накладок. Процедурные жесты GDScript и blink не запекаются в GLB; скелет/веса/материалы экспортируются. Новых зависимостей/моделей извне не добавлено.

Сохраняются внешний API GuestArt, выбор D/A/B/C, ServiceGuest, коллизии, речь/подача и сохранения. Внутреннее дерево VisitorModel изменилось; потребители visitor_model_test/capture_visitor обновлены. is_blinking — диагностическое состояние для них. [Контракт и ограничения](../CHARACTER_PROTOTYPE.md).

Это технически проверенная художественная итерация. Субъективное «идеально» и финальная художественная приёмка не выводятся из тестов. Нет липсинка/ходьбы/IK; DA-035 целиком не закрывается.
