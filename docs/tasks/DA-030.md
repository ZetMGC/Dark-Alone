# DA-030: Первый художественный проход

Статус: done. Владелец: агент DA-030. Ветка `codex/da030-atmosphere`, база `3c2f4cb`. Этап M3.

## Зачем и результат

Заменить вид graybox первым вариантом мрачного PS1-бара в современной подаче. Q-02 выбран владельцем: цветные люди, приглушённый серый бар, пока без рук игрока.

## Зависимости и границы

DA-024 завершена в базе. Общие сцены BarLevel/Main/NavigationHUD/TestGuest редактирует только агент DA-030; других назначенных редакторов в BACKLOG нет. Новые модули — scripts/presentation, scenes/presentation, assets/shaders. Сюжет, перемещение, коллизии и данные диалога не меняются. Решение — ADR-0008.

- [x] Фоновый гул регулируется, ноль отключает звук.
- [x] Все игровые проверки и новый тест настроек проходят.
- [x] Все якоря, обзор, меню/диалог/дневник просмотрены в обычном и минимальном окне.
- [x] Собранная Windows-игра проходит сквозную проверку с оформлением.
- [x] Результат, параметры, происхождение ресурсов и продолжение записаны.

Инструкция автору — [ART_GUIDE](../ART_GUIDE.md), фактические проверки и передача — [worklog](../worklog/2026-10-26-08-first-art-pass.md).
