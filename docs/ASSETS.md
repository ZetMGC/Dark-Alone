# Ресурсы и права

В игровых сценах M0 сторонних изображений, моделей, шрифтов и звуков нет. Стартовая сцена использует стандартные средства Godot. Исходная доска команды сохранена в `docs/sources/concept-board.png` как материал концепта, не как игровой ресурс.

В DA-022 сцена `scenes/characters/test_guest.tscn` создана из примитивов Godot внутри проекта, без сторонних моделей, текстур и звуков. Она является TEST-заготовкой, авторский источник — текущая разработка репозитория. Материалы Mouthwashing в игру не включались; ссылка в VISUAL_DIRECTION — только визуальный ориентир. Публичная лицензия проекта по-прежнему не выбрана.

DA-034: `scripts/ui/book_art.gd` — собственный рисунок обложки/бумаги/ленты примитивами Godot; `JournalPanel._make_rustle` — собственный синтезированный PCM-шелест, без внешней записи. `scenes/ui/book_theme.tres` ищет Georgia/Noto Serif/Times New Roman через SystemFont, затем fallback движка; файлы системных шрифтов не копируются и не распространяются. На другой ОС внешний вид и пагинация могут отличаться. Лицензия собственного кода проекта отдельно не выбрана.

Не считать «бесплатно скачать» разрешением на коммерческое использование. Финальные сторонние ресурсы должны иметь понятные условия. Выбор лицензии собственного кода и контента пока не сделан; файла LICENSE намеренно нет.

DA-035: TestFace/guest_art — собственная геометрия головы/носа/глаз/век/ушей/губ из ArrayMesh и примитивов Godot. Текстур/моделей/портретов третьих лиц и генерации изображений нет. Снимки preview/gameplay сделаны самим движком из TEST-моделей; не являются утверждёнными портретами персонажей. Лицензия собственного проекта отдельно не выбрана.
