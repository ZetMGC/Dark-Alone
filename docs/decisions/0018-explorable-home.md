# ADR-0018: Исследуемый дом и отдельный прогресс наблюдений

Дата: 2026-10-26. Accepted для DA-049 по прямому запросу пользователя: сделать основу дома с отдельными событиями/исследованием.

## Решение

Создать независимую TEST-сцену дома на тех же якорях/камере/Interactable3D, включить её в HOME существующего commute. Main создаёт сцену динамически, не меняя общую main.tscn. В текущем World3D она смещена на 32 м, чтобы скрытые коллизии комнат не мешали друг другу; это техническое размещение, не канон. Дом выбирает собственную камеру при HOME и удерживает фон для меню/книги; на обратном пути прежний Main перезагружается.

HomeState (RefCounted) владеет множествами завершённых осмотров/событий. Определения TEST отделены; доступны только заранее известные ID, условия всех required observations и однократное завершение. Осмотр и событие требуют явной кнопки завершения; Escape отменяет. Прогресс передаётся между обычными сменами в RUN_HANDOFF.home_state, отдельно от Journal. Полный тестовый reset и выход из процесса очищают его. Никаких новых терминов/затрат времени, дисковых сохранений и сюжетных наград.

Домашний осмотр — локальное модальное представление внутри HOME; Session по-прежнему владеет MENU/JOURNAL/TRAVEL. Дом блокирует собственную камеру/цели при осмотре и сохраняет осмотр при чтении книги. Скрытые кнопки и прежний fallback дома не могут завершить осмотр/отправить героя на работу. Команда выхода доступна только у двери вне перехода/осмотра.

## Совместимость и проверка

configure_commute добавляет необязательный explorable_home=false; старые изолированные потребители сохраняют экран. Main передаёт true, использует HomeExploration вместо старых Work/Journal, обязательный HOME меняется визуально, не в модели маршрута. HomeState в handoff необязателен для старых передач; неверный тип даёт явный отказ. Камера получает apply_preferences() без нового UI. Тесты commute/playthrough обновлены на фактический домашний UI, отдельный home_test проходит в headless/на GPU. Будущие сюжет/инвентарь/ветвления требуют отдельного решения; HOME.md описывает расширение текущего задела.
