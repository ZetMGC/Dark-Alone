# Dark Alone v0.1.0-alpha.2 — тестовый билд

Windows x86_64 · Godot 4.7.2 · Compatibility. Чистый main `0dadbdfc88bdcaa34c7db14b449f605120a83ba3`.

## Новое после alpha.1

- **Графика под разрешение экрана:** режим «Под экран» увеличивает число видимых деталей вместе с разрешением; «Чёткая» использует каждый пиксель, «Классическая» сохраняет прежние 360 строк.
- **Чётче текст:** стандартные шрифты интерфейса/надписей и отдельный шрифт книги переведены на масштабируемую MSDF-отрисовку.
- **Временные TEST-лица A/B/C:** разные челюсти, носы, скулы и брови; выбор в меню «[TEST] Лицо гостя» меняет только внешность, сохраняет разговор/заказ/время.
- Готовые ветки объединены в main и удалены с сохранением истории.

По решению владельца эти лица оставлены временно. Будущий художественный ориентир — **реалистичные персонажи** в близком ощущении к *No, I'm not a Human*, возможно немного менее реалистичные. Текущая угловатая геометрия не является финальной целью; дальнейший арт отложен. Это уточнение записано в CHARACTER_DIRECTION/ADR-0015.

## Запуск и проверка

В **Assets** скачать **Dark-Alone-v0.1.0-alpha.2-windows-x86_64.zip**, распаковать всю папку и запустить **Dark Alone.exe** рядом с PCK. Godot не нужен. Source code.zip/tar.gz — исходники, не готовая игра. START-HERE.md в архиве содержит управление и маршрут проверки.

1–4 — точки, ПКМ + мышь — обзор, T — разговор, B — напиток, J — дневник, Escape — меню, F11 — полный экран. В меню сравнить детализацию на своём экране. Полный цикл: разговор/напиток → два деления → итоги → домой → следующая смена. Дневник хранит знания/закладки/место чтения между обычными сменами.

## Выполненные проверки

Полный набор исходников и штатный запуск. Windows release template headless: цикл 50, книга 51, экран 46, лица 22 — без ошибок. Графический экспорт: цикл 52, экран 54, лица 38, детализация 18 — без ошибок. В 4K GPU-мишень сохраняет 575 границ при adaptive против 0 при старых 360 строках. ZIP распакован вне проекта, SHA256 файлов совпали с manifest, EXE запущен графически без редактора.

Среда: Windows 11 Pro, RTX 5060, Compatibility; один физический экран 1920×1080, окна/рендер до 3840×2160 и ultrawide. Другие компьютеры/DPI/физические мониторы требуют проверки коллегами.
