# Dark Alone v0.1.0-alpha.1 — первый тестовый билд

Windows x86_64 · Godot 4.7.2 · Compatibility. Коммит `391dbcb8e8e78f08e58d7c4d7117a4c4d8705c28`.

## Что есть

- Бар с перемещением по четырём точкам, TEST-разговор с выбором и подача напитка.
- Смена на два деления, итоги и переходы домой/на следующую смену.
- Дневник-книга: страницы и листание, поиск, новые записи, закладки и место чтения между обычными сменами.
- Мрачное PS1-оформление, отключаемый ретро-эффект, настройки звука и анимаций.
- F11 или меню: окно/полный экран, выбор монитора, масштабирование интерфейса под разные разрешения.

## Как запустить

В **Assets** скачать **Dark-Alone-v0.1.0-alpha.1-windows-x86_64.zip**, распаковать всю папку и запустить **Dark Alone.exe**. Файл PCK должен лежать рядом. Godot не нужен. Source code.zip/tar.gz — исходники, не готовая игра.

В архиве есть START-HERE.md с управлением и маршрутом проверки. Быстрое управление: 1–4 — точки, ПКМ + мышь — обзор, T — разговор, B — напиток, J — дневник, Escape — меню, F11 — полный экран.

## Что проверено

Полные проверки исходников, штатный запуск экспортированной игры и проверки release template: игровой цикл 50, дневник 51, экран 46 — без ошибок. Графический экспорт: игровой цикл 52, экран 54 — без ошибок. ZIP распакован вне проекта, контрольные суммы файлов совпали с manifest, обычный EXE запущен без редактора.

Среда: Windows 11 Pro, NVIDIA RTX 5060, Compatibility, физический экран 1920×1080; размеры окна/рендера 960×600…3840×2160, включая 4:3 и ultrawide. Другие физические мониторы/DPI и другая машина требуют проверки коллегами.

## Ограничения и обратная связь

Это **Pre-release**, прототип до MVP: TEST-тексты и TEST-гость. **Нет сохранения на диск** — после закрытия игры прогресс теряется. Обычная следующая смена сохраняет дневник в памяти, прямой тестовый сброс очищает его. Узнаваемые лица и реалистичная подача записей — будущие этапы.

При ошибке сообщить `v0.1.0-alpha.1`, Windows/видеокарту/разрешение, шаги, ожидаемый и фактический результат. Инструкция и расположение логов — START-HERE.md. Для проверки ZIP приложены SHA256SUMS.txt и build-manifest.json.
