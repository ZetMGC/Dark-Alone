# ADR-0044 — действия верстака по ситуации

Принято, DA-083, прямое поручение владельца 2026-10-29. Вместо постоянной панели крышек/неактивной выдачи — одно действие шейкера по состоянию и завершение только при готовности. E и клик выполняют одно действие; для выбора контекста достаточно навести мышь на шейкер. Короткая подсказка наверху меняется при переносе/готовности. Выбор посуды остаётся явным и доступен при перекрытии полки. Модель жидкости/техники не упрощается. TEST-сода получила PNG, остальная графика постепенно может быть заменена отдельно.
