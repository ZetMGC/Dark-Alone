# ADR-0022: Последовательные пузырьки речи

Дата: 2026-10-27. Статус: принято по отзыву владельца. DA-054, уточняет ADR-0021.

Владелец попросил сделать речь прозрачнее/мельче и заменить прокрутку следующим пузырьком. Фон alpha 0,78, шрифт 18, мягкая рамка, короткий текст уменьшает высоту. Список ответов сохраняет прежнее оформление.

SpeechPaginator измеряет смешанный normal/bold через TextParagraph. Продолжения сохраняют точные plain-диапазоны/выделение, непарные маркеры остаются буквальными. F раскрывает текущий фрагмент, затем открывает следующий; ответы и завершение только на последнем. Паузы и отворот сохраняют текущий фрагмент. Переход — UI, не новый узел/эффект Runner. Scrollbar и PgUp/PgDn речи удалены, данные контента/сохранений не меняются.

Это ручное продолжение по F без таймера автопропуска, чтобы успевать читать. Размер шрифта/прозрачность требуют пользовательской оценки. Публичные методы — [CONTRACTS](../CONTRACTS.md), управление — [DIALOGUE_BUBBLES](../DIALOGUE_BUBBLES.md).
