# DA-057: Постоянные настройки игрока

Статус: in_progress. Владелец: агент DA-057. Ветка codex/da057-persistent-settings, база 1b748d3.

Владелец выбрал продолжать технические механики, сюжет позже. Устранить известное ограничение: настройки звука/изображения/камеры/книги/окна живут только в процессе. Не менять канон, баланс, отложенные лица/записи или механику прогресса. Настройки хранятся отдельно в user://, «Начать заново» их не удаляет.

Объём: проверяемый JSON настроек, атомарная замена, сохранение изменений с задержкой и при выходе/смене; загрузка без частичного применения, безопасный fallback монитора/размера окна, сообщение ошибки и сброс настроек. TEST-внешность и рабочий прогресс в этот файл не входят. Main/HUD редактирует один агент, рабочая копия чистая.

Приёмка: отдельный новый процесс восстанавливает значения и реальное меню Main; изменения через F11/ползунки сохраняются, новый старт не удаляет предпочтения; неправильный/несовместимый файл не ломает запуск; тесты не трогают файлы пользователя; headless/GPU/Windows проверены, документы переданы. Истории Q-04 остаются открытыми и не реализуются этой задачей.
