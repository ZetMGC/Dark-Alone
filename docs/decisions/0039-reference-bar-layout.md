# ADR-0039: игровая адаптация плана бара

2026-10-28, прямое поручение участника по изображению. Принимаем основной габарит 10×8 м и расположение зон. Подпись 60 м² противоречит размерам, поэтому её не используем для масштабирования. Задний тамбур — небольшой выступ за основной габарит.

ReferenceBar — самостоятельная процедурная локация с физическими стенами/мебелью, подключена через Main.reference_bar_enabled в reasoning_demo. Общую main.tscn/старый graybox не заменяем: старые fixtures продолжают проверять исходные контракты. Сцену reasoning_demo изменяет только этот исполнитель.

Сохраняются пути интерактивных поверхностей/идентификаторы якорей, рабочий стол перемещается и его якорь получает единичный масштаб. Новая явная точка подачи и параметризованные entrance/waypoints VisitorBehavior заменяют координаты старого зала только в новой локации. Формат диалогов/сохранений/рецептов прежний.

Первый проход геометрии/отделки/освещения, внешние двери пока закрыты. Утверждение финального арта по скриншотам не подразумевается. Потребители: Main, reasoning_demo, VisitorBehavior, reference_bar_test; общий check включает новый тест.
