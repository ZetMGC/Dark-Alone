# Запуск и рабочая среда

## Новый участник

1. Клонировать `https://github.com/ZetMGC/Dark-Alone.git` в отдельную локальную папку и выбрать нужную ветку. M1 и DA-020 уже в main. Текущая DA-021 — `feat/DA-021-dialogue-journal`; до её слияния разговор и дневник брать из этой ветки. Не делить один рабочий каталог через OneDrive между несколькими редакторами: Git и локальный кэш Godot требуют независимых копий.
2. Установить Git и скачать [Godot 4.7.2 Standard](https://godotengine.org/download/archive/4.7.2-stable/). Закреплённая версия хранится в `.godot-version`. Файл движка не включён в репозиторий.
3. В менеджере проектов Godot выбрать Import → корневой `project.godot`. При первом открытии дождаться импорта.
4. Нажать F5. ПКМ + мышь / стрелки — обзор, 1–4 — переходы. У стойки E по метке или T — TEST-разговор. Tab/Enter или мышь — ответ; J — дневник и возврат; Escape — меню, а из дневника — возврат. Подробности — M1_NAVIGATION и DIALOGUE_RUNTIME.
5. Прочитать STATUS и HANDOFF, выбрать задачу, создать ветку.

## Проверки в PowerShell

Если `godot` есть в PATH:

```powershell
pwsh -NoProfile -File tools/check.ps1
```

Если нет, передать абсолютный путь к Standard console executable:

```powershell
pwsh -NoProfile -File tools/check.ps1 -Godot 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe'
```

Путь — пример, его нужно заменить своим. Если используется Windows PowerShell 5.1, вместо `pwsh` можно вызвать `powershell`. Не менять глобальную execution policy ради проекта. Если политика организации запрещает скрипты, использовать ручные команды из TESTING согласно её правилам.

Скрипт проверяет версию, импорт, главную сцену, M1, контент, загрузчик, исполнение разговора, Journal, модальный UI и краткий запуск. Коды ошибок и сообщения `ERROR:` считаются провалом. Визуальная проверка отдельная: TESTING содержит команды снимков. Авторам контента доступна отдельная команда из DIALOGUE_CONTENT.

## Общий репозиторий — DA-002

Владелец опубликовал репозиторий, origin настроен, M1 и DA-020 слиты. Получение текущей ветки DA-021:

```powershell
git clone https://github.com/ZetMGC/Dark-Alone.git
cd Dark-Alone
git switch feat/DA-021-dialogue-journal
```

Слияние новых веток в main выполняется после ревью. Ещё нужно согласовать ответственного за интеграцию, права коллег, проверить clone и запуск коллегой, назначить CI. Приватность не менялась агентом; публичная лицензия не выбрана.

## Большие ресурсы и экспорт

В M0 внешних зависимостей нет. До добавления больших ассетов решить вопрос LFS и лимитов сервера. Экспортные профили, шаблоны и CI появятся с задачами сборки. Секреты экспорта не коммитить. `builds/` и `artifacts/` исключены из Git.

## Частые проблемы

- Другой Godot: не пересохранять проект новым движком молча; свериться с `.godot-version`.
- Нет `godot` в PATH: указать `-Godot` с полным путём.
- После переноса пропали ресурсы: сохранить `.uid` и `.import` sidecar-файлы, проверить регистр путей и повторить импорт. `.godot/` не переносить.
- Конфликт сцены: не выбирать весь «свой» или «чужой» файл автоматически; согласовать владельца, затем открыть и проверить сцену.
- Невозможно запустить движок: записать причину в handoff; просмотр текста сцены не заменяет запуск.
