# ADR-0032: пузырёк выбора вывода

Статус: принято, DA-070, прямое поручение владельца 2026-10-28.

Вместо списка в отдельной области правой страницы варианты появляются компактным плавающим пузырьком у точки выбранной группы. Высота зависит от переноса текста, сторона/позиция ограничена разворотом. Рукописный шрифт, мягкая тень, подсветка строки под курсором, без нумерации. Выбор мышью; клик снаружи/Esc отменяет без изменения модели, повторный клик по строке после commit ничего не меняет. Цифры не выбирают вывод.

Потребители get_option_rect обновлены и проверены кликами в реальном viewport. Условия/запись/цепочки/сохранения прежние, нового API модели нет. Общие .tscn не меняются. Последствие: геометрия popup вычисляется в координатах PaperPages и меняется при изменении размера окна; координаты не сохраняются.
