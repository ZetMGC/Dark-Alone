## Выполнено

Владелец уточнил: круг должен появляться автоматически, вариант открывает маленькая точка, стрелки — после связанных выводов. Из PaperPages удалены stroke/drawing/распознавание жеста. ready-группа получает овал/точку, клик открывает прежние варианты с теми же ID/evidence; сформированный вывод убирает точку. Новое open_conclusion отклоняет скрытый/неготовый/уже завершённый контекст и раздел рецептов. Стрелки вычисляются из авторских reasoning_links только после обоих выводов и optional required_conclusions. Связи валидируются; они не доказывают истинность, в файл отдельно не записываются.

Выявлены причины мигания: изменялась ширина бумаги/пороговое появление букв при открытии, preview текста рисовался вручную иначе, целевой снимок убирался до отложенной реальной пагинации. Теперь книга поднимается цельным раскрытым разворотом. Перелистывание получает два изображения от одного JournalPanel с одинаковой сценой/шрифтами/размером: target рендерится в отдельном SubViewport на независимой Journal.make_visual_copy. Источник/цель используются для неподвижных половин и обеих сторон изогнутого листа. После commit фаза settle держит кадр до завершения live layout. Временные объекты/текстуры освобождаются; пауза/отмена/режимы и отдельный шелест сохранены. Прежняя имитация распахивания обложки снята, это 2.5D-подъём раскрытой книги, не новая 3D-бумага.

## Контракт и ограничения

[ADR-0030](../decisions/0030-automatic-groups-stable-pages.md), дополнение [JOURNAL_REASONING](../JOURNAL_REASONING.md). Catalog.get_reasoning_links; Reasoning.configure(groups, links=[])/get_link_definitions/get_links(sheet); Journal.make_visual_copy; PaperPages.open_conclusion/get_conclusion_button_rect/get_visible_links/get_page_preview. Сигналы Session/схема conclusions/evidence/граница следующей смены прежние. Круги/стрелки не сохраняются отдельно. ID групп/версий не менять по смыслу без миграции.

Рендер подготавливает изображения на GPU асинхронно, может добавить несколько кадров перед началом листа; повторные команды блокируются, пиксели/viewport не сериализуются. При отмене/закрытии serial защищает callback, меню приостанавливает подготовку и движение. Авторы размещают группы без наложений; связи только одного разворота. В основном TEST-контенте одна группа, стрелки появятся после добавления утверждённых связанных групп. Конкретный сюжет/правильность интерпретации/распознавание напитков этим не придумываются. Новых зависимостей/ассетов нет. Физические мониторы и субъективную плавность оценивает человек.
