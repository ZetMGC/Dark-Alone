# HOME-02: небольшой дом

Прямое поручение второго участника 2026-10-27: реализовать обсуждённый в чате небольшой дом. Это продолжение после DA-062, база d4e4de1, ветка codex/da062-home-object-targets. Статус: реализация готова, итоговые проверки в WORKLOG. Работа только в домашнем модуле и его проверках/документации; бар и общие системы не редактируются.

Прихожая, кухня-гостиная, спальня и санузел; свободная ходьба, коллизии, бытовая мебель и действия. Прежние четыре наблюдения/TEST-событие и формат checkpoint сохранить. Новые бытовые состояния локальные, не считаются заданиями/каноном и не расширяют сохранение. Кровать пока осматривается, сна/нового календаря/расхода времени нет. Обновлённая планировка должна проверяться настоящей ходьбой и реальными лучами; DA-062/legacy/общий набор также выполнить.

## Реализованная планировка

Внешний размер пола 8,6 × 7,6 м (около 65 м²), потолок 2,94 м; дверь на юге. Координаты относительно HomeExploration, X вправо, -Z вверх на плане. Два прохода между гостиной/прихожей и спальней сохраняют прежний пеший маршрут; один со сдвижной дверью. Санузел отделён стеной и собственной сдвижной дверью.

```text
                       СЕВЕР · Z=-4,5
┌──────────────────────────┬─────────────────────┐
│ Кухня: чайник, холодильник│ Стол, лампа, шкаф   │
│                          │                     │
│ Окно   Обеденный стол     проход           Окно│
│        Стул              │                     │
│ Диван  Стол с книгой      │                     │
│ Радио                    │ Кровать, часы       │
├─────────┬──── проход ────┤                     │
│ Раковина│                дверь спальни         │
│ Зеркало дверь ПРИХОЖАЯ   │                     │
│ Душ, WC │ Ключи, вешалка │                     │
└─────────┴──── ВХОД ──────┴─────────────────────┘
                        ЮГ · Z=3,1
```

Границы: гостиная X<0/Z<0,6; спальня X≥0; прихожая X=-3,2…0/Z>0,6; санузел X<-3,2/Z>0,6. Проёмы 1,1–1,7 м. Капсула 0,48 м и прежняя скорость камеры не менялись.

## Взаимодействия

| Место | Действия |
| --- | --- |
| Прихожая | Прежний осмотр входной двери и выход на работу; осмотр ключей/куртки, переключатель света |
| Кухня-гостиная | Чайник: нагреть 6 секунд активного HOME → выпить; отмена нагрева повторным E; холодильник открывается/закрывается; осмотры обеденного стола/окна; шторы; радио вкл/выкл с тихим процедурным сигналом; можно сесть на диван/стул и встать Escape; отдельный свет |
| Спальня | Прежние кровать/окно; осмотр второго письменного стола/часов, лампа и основной свет, открываемый шкаф, штора, сдвижная дверь |
| Санузел | Кран/умыться, осмотры зеркала/душа/WC, открываемый шкафчик, свет и сдвижная дверь |

Всего 26 новых логических целей действий плюс прежние четыре предмета DA-062. Навести прицел на видимый предмет и нажать E, радиус бытового действия 2,5 м. Свежий луч не проходит стены. В новых местах сидения остаются дневник/встать; чужой осмотр не предлагается. У бытовых осмотров кнопка «Закрыть» не выдаёт отметки HomeState. Сюжетного текста, новых заданий или новых затрат времени нет.

## Реализация и расширение

scenes/home/house_interior.tscn — отдельная сцена с scripts/home/house_interior.gd. Геометрия собирается при build(home) из собственных Mesh/StaticBody; размеры и разметка в build/_build_entry/_build_living/_build_bedroom/_build_bath. У крупных объектов физические коллизии, декоративные детали без коллизий. Старые четыре объекта/их координаты сохранены; заменены только наружные стены/пол/потолок в free-roam. Legacy free_roam=false по-прежнему получает старую TEST-комнату для контрактных fixtures.

HomeExploration создаёт дом до configure камеры, чтобы два новых места сидения входили в валидный граф камеры. Саму камеру/общие сцены/бар не меняли. HouseActionTarget — локальный адаптер существующего Interactable3D/register_surface, без собственной Shape. Сдвижная дверь проверяет капсулу до закрытия; шкафные дверцы открываются вокруг петли. Радио использует собственный короткий периодический PCM с guard-отсчётом, зависит от общего get_ambience_gain и выключается вне активного HOME/при выходе.

Свет, дверцы, шторы, вода, чай и радио сбрасываются с новым экземпляром локации. HomeState/Journal/checkpoint v1 прежние; бытовые состояния не сохраняются на диск. Календарь/сон/новые домашние события не реализованы. Зеркало стилизовано материалом, настоящего отражения героя нет; радио не содержит станций/речи, только тестовый звуковой сигнал. Это играбельная основа интерьера, не финальные арт и сценарий.
