# WORKBENCH-02 — инерция, поверхность, доступность и запасы

Статус in_progress. Агент владельца, ветка codex/workbench-physics, база 49ab5d5. Прямой отзыв владельца: бутылки качаются от энергии курсора, пролив падает на поверхность рядом с наливом, стакан слева остаётся доступен, слои требуют ложку, содержимое бутылок расходуется. Зависимость WORKBENCH-01 выполнена. Область: scripts/ui/preparation, tests/parallel/bar/workbench_test.gd, docs/parallel/bar; сцены/дом/общие runner не редактировать.

Приёмка: затухающая инерция влияет на вид/струю; движение/налив останавливаются при паузе. Пролив имеет место удара на рабочей плоскости и расплывается по ней. Реальный стакан берётся даже поверх зоны чистой посуды и прочих предметов; замена пустой посуды явная. Для совместимых TEST-жидкостей прямой налив смешивает, мягкий через ложку сохраняет порядок по плотности. Конечные запасы расходуются на всё вышедшее из бутылки, включая промах/переполнение; отрицательные остатки/бесконечная струя исключены, UI показывает уровень. Повторное открытие/смена посуды запас не восстанавливают. Профиль headless/GPU двух размеров, общий набор и документы передачи обязательны. Это игровой способ укладки слоями, не утверждение универсального закона физики.
