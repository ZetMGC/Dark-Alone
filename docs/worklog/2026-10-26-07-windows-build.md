# 2026-10-26: DA-024 — полный цикл и автономная Windows-сборка

Исполнитель: агент DA-024. Ветка: `codex/da024-team-build`. База: `dce6a0b`. Начальное дерево чистое, локальный main был впереди origin/main на один коммит. Fetch подтвердил origin/main=`07bed83`; ветка включает ещё не слитый DA-023. Чужая работа не изменялась, сцены мира не редактировались.

## Выполнено

Подготовлен комплект Windows x86_64 без редактора: exe/PCK, инструкция, правовые уведомления Godot и manifest с source_revision/source_dirty, версией, UTC-временем и SHA256 файлов. Каждая команда сборки создаёт новую папку и ZIP, не удаляет прежние. Архивы игнорируются Git, публичная публикация не выполнялась, коллегам сообщения не отправлялись.

Добавлен сквозной проход настоящего Main: обе ветки, вода и напиток бара в разном порядке, маршрут всех якорей, отмены, дневник, пауза, итог и новая смена. Отдельный Windows Validation запускает этот тест в release template через feature override стартовой сцены; обычный пресет исключает тесты. Main не получает тестовых веток.

Экспорт выявил реальную проблему: после преобразования текстовой сцены связи AnchorPoint.neighbours становились пустыми и переходы блокировались, хотя ввод доходил до Main. Исходники работали. Отключение преобразования текстовых ресурсов устранило проблему. Формат скриптов оставлен 2; сам по себе его переход в текст проблему не решал. Диагностика из Main удалена. Решение — [ADR-0007](../decisions/0007-windows-export.md).

Имена локальных архивов в Git не закрепляются — они выводятся сборщиком.

## Решения и ограничения

Сборка локальная, не опубликована и не отправлена третьим лицам. Тестируемый PCK отличается от игрового тестовыми ресурсами и стартовой сценой; обычный PCK отдельно проходит запуск штатного Main. Автоввод — события viewport и сигналы кнопок, не физические клавиши. Другой компьютер, права коллег, субъективный комфорт, финальная производительность и экспорт M3 не проверялись. Нет сюжетного/художественного наполнения M3, сохранений и CI. Лицензия Dark Alone не выбиралась.
