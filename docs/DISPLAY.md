# Экран, мониторы и масштабирование — DA-037

F11 переключает окно/полный экран из любого игрового экрана, включая дневник и меню. Удержание клавиши не вызывает повторных переключений. В Escape → «Экран · F11» доступны те же два режима; ниже выбирается подключённый монитор с его текущим разрешением. Полный экран использует родное разрешение выбранного монитора без смены видеорежима Windows. При возврате восстанавливаются размер/позиция окна или развёрнутый режим; на другом мониторе окно ограничивается доступной областью и центрируется.

Масштабирование UI: `canvas_items`, база 1280×720, aspect `expand`, минимальное окно 960×600. Масштаб по осям одинаковый, широкие/высокие экраны получают дополнительную область, текст рисуется в разрешении экрана. 3D и ретро-эффект остаются отдельными от UI; fullscreen не означает фиксированную низкую 3D-разрешающую способность. HiDPI не отключается. Для редакторского встроенного окна переключатели недоступны: запускать игру в отдельном окне. DA-057 сохраняет режим/монитор/размер/развёрнутое состояние на диск отдельно от прогресса; позиция сохраняется только в процессе. При новом запуске окно вписывается в доступный экран, см. PLAYER_SETTINGS.

Реализация: `scripts/presentation/display_settings.gd`, отдельный Node в Main. Он связывает `%DisplayMode`/`%DisplayMonitor` NavigationHUD, не обращается к игровым моделям. Список экранов обновляется раз в секунду; фактический выбор зависит от Windows/драйвера. Не обещать проверку горячего отключения монитора или иной ОС без отдельного прогона. Настройки в меню прокручиваются при необходимости, кнопки продолжения/выхода остаются вне прокрутки.

## Проверить

После DA-042 размер окна также увеличивает видимую детализацию мира: режим «Под экран» использует блоки 2 физических пикселя вместо прежних фиксированных 360 строк. Стандартный/книжный шрифты MSDF, варианты «Чёткая/Классическая» — IMAGE_DETAIL. Canvas_items/expand по-прежнему управляет компоновкой, не ограничивает количество пикселей эффекта.

```powershell
godot --headless --path . res://tests/display_test.tscn
godot --path . res://tests/display_test.tscn -- --capture-dir=<абсолютная-папка>
```

Матрица: 960×600, 1280×720, 1280×960 (4:3), 1920×1080, 2560×1440, 3440×1440, 3840×2160. Headless проверяет компоновку/безопасный отказ оконных действий, графический запуск — реальный F11, меню и native fullscreen, повтор клавиши, возврат размера и доступные физические мониторы. Снимки `da037_menu_*`, `da037_book_*`, `da037_fullscreen.png`; фактические размеры PNG должны соответствовать матрице. Экспорт Windows Validation принимает `-- --display-check`; production Main такого аргумента не содержит. Другие физические экраны/DPI Windows должны проверить коллеги.

Новые интерфейсы — CONTRACTS, выбор — ADR-0012, результат — последняя запись worklog. Не хранить размер UI как игровой прогресс или страницу дневника; resize пересчитывает страницы по reading_offset.
