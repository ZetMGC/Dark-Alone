# ADR-0037 — ненавязчивый интерфейс

Статус: принято по прямому запросу владельца 2026-10-28.

Постоянные нижние инструкции заменены краткими пассивными уведомлениями в углу. Повторы подавляются в рамках UI-сессии; игровой прогресс не хранит факт показа. Прицел — небольшая точка с плавным переходом в кольцо по доступности реального действия, включая дом. Название/остаток/крепость бутылки показываются у курсора только до захвата. Меню использует ограниченную ширину и 40 логических единиц высоты кнопок вместо растяжения по ширине экрана; настройки прокручиваются по высоте.

Причина: освободить вид на мир, сохранить обратную связь и доступность действий. Единого численного стандарта для всех игр нет; размеры выбраны под текущий шрифт и проверяются от 960×600 до 4K. Контракты ввода и сохранений не меняются. Публикация нового релиза этим решением не производится.
