# ADR-0033: только доступные ответы и спокойная панель

Принято: 2026-10-28, DA-071, прямое поручение владельца.

Причина: яркая фиксированная панель отвлекает, остаётся пустой у terminal, скрытые условия создают несогласованные номера после дневника.

Решение: отфильтровать недоступные варианты перед UI, индексировать номера/цифры/колесо/F единым видимым списком. При обновлении того же узла сохранять выбранный choice_id, не позицию; новые строки могут вставляться перед ним. Окно ответов скрывать при terminal/пустом списке/неактивном Runner; завершение terminal остаётся через F и отдельную подсказку. can_answer не равен visible: terminal нужен для confirm. Панель приглушённая, высота по содержимому с ограничением и прокруткой длинного списка.

Последствия: закрытые ответы/требования не показываются, игрок видит только доступные реплики. Публичный индекс submit_choice/selected_index относится к видимому списку; input и fixtures согласованы. Runner по-прежнему перепроверяет условия. Старый модальный fallback, модель/контент/сохранения не меняются.
