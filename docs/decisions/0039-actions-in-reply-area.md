# ADR-0039 — расположение действий

Принято по прямому уточнению владельца 2026-10-28. Действия должны находиться в области ответов диалога, а не у объекта. Рядом с действием показываются действующие клавиши выполнения. Пассивные сведения остаются в объектном пузырьке. Это заменяет часть ADR-0038 о совместном размещении сведений и действий. Сохраняются проверка актуальной цели, лаконичный стиль, исчезновение при отведении взгляда и обновление одной локальной установки.
