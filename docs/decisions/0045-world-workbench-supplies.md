# ADR-0045 — предметы из мира в рабочую зону

Принято 2026-10-29, прямое поручение владельца DA-085. Начальная 2D-поверхность пуста. Ящики/полка используют обычный Interactable3D, единый слот DrinkCarry ограничивает перенос одним предметом. Порция null отличает инструмент от напитка; передача гостю инструментов исключена. Добавление в 2D одноразовое; модель жидкости создаётся отдельно от присутствия предмета, отсутствующие приёмники исключены. Несколько типов посуды хранят собственные смеси. Стойка открывает service напрямую, промежуточный focus убран в обычном запуске. Старые main-based fixtures сохраняют прежний режим явно через флаг по умолчанию false, reasoning_demo включает новый.
