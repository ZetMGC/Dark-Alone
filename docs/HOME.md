# Дом: исследование и события — DA-049

HOME-02 по следующему прямому поручению второго участника: в режиме свободной ходьбы вместо одной TEST-комнаты небольшой четырёхкомнатный дом с мебелью, светом и бытовыми действиями. [План, список взаимодействий и границы](parallel/home/HOUSE_PLAN.md). F5 → завершить смену → «Домой»; WASD/мышь, прицел + E, J — дневник, Escape — отменить/встать/меню. Основной бытовой прогресс не записывается, прежние четыре наблюдения/событие сохраняются по SAVES. В старых графовых fixtures остаётся прежняя комната.

DA-062: при ходьбе наводить прицел на саму дверь, стол/книгу, окно или кровать и нажимать E. Плавающие метки и прежние сферы отключены. Вблизи открывается локальный ракурс с курсором; E по поверхности открывает осмотр, кнопка осмотра остаётся альтернативой. Escape сначала отменяет осмотр, следующий возвращает к месту подхода, затем открывает меню. Якорь двери в режиме ходьбы развёрнут к двери; положение тела/прежний граф не меняются. Подробности и проверки — [контракты домашней дорожки](parallel/home/CONTRACTS.md), [передача](parallel/home/HANDOFF.md).

DA-052: теперь дома WASD/мышь, рядом с точкой E открывает фиксированный ракурс с курсором/осмотром; Escape возвращает к месту подхода. Старые цифровые направления и нижняя навигация при ходьбе скрыты. Прежние инструкции по графу ниже относятся к старому контракту. [FREE_ROAM](FREE_ROAM.md).

DA-050: небольшие начальные наклоны стола/кровати сохраняются для видимости предметов, но поворот по сторонам всегда вокруг вертикали мира. Завала горизонта при обзоре больше нет; R возвращает исходный ракурс. Это исправление камеры, не поворот мебели/комнаты.

Это черновая TEST-комната и основа будущих домашних эпизодов. Планировка/предметы не утверждают биографию героя, адрес, сюжет, сон или экономику.

## Как попасть и проверить

F5 → завершить смену двумя действиями → «Домой» → закончить/пропустить дорогу. WASD/мышь — ходьба и обзор; подойти к нужному предмету, навести прицел и нажать E. В открывшемся ракурсе навести курсор на предмет и нажать E либо «Осмотреть у этой точки». В старых контрактных fixtures free_roam=false остаются цифры 1–4/граф/ПКМ.

«Завершить осмотр» ставит отметку, «Назад»/Escape отменяет без отметки. Повторное чтение не дублирует её. После стола и окна появляется [TEST] Событие; завершение ставит отдельную одноразовую отметку, отмена оставляет его доступным. Время бара и дневник терминов не меняются. Событие не обязательно для выхода.

J открывает прежнюю книгу и возвращает в комнату/текущий осмотр. Во время модальных экранов камера/взаимодействие дома отключены. Для выхода подойти к двери, открыть её ракурс через E и нажать «На работу». На дороге дом скрывается, следующая смена возвращает камеру бара.

## Состав и расширение

- scenes/home/home_exploration.tscn: геометрия из block.tscn, свет, четыре AnchorPoint, четыре HomeObject, отдельные камера/взаимодействие и домашний HUD. Редактировать независимо от бара. Положения якорей — глаза, единичный масштаб; проверить прямой/обратный маршрут и коллизии.
- scripts/home/home_object.gd: Interactable3D с object_id/required_anchor/title/description и сигналом inspect_requested. Каждый объект сейчас привязан к одному якорю. Кнопка осмотра не требует видимости, луч E требует; оба пути повторно проверяют якорь/режим/переход.
- scripts/home/home_state.gd: RefCounted с завершёнными осмотрами/событиями. OBJECTS содержит стабильные ID; EVENTS — только TEST-описания и requires. Прогресс отдельный от определений, геттер событий возвращает копии. Нельзя вызывать код из данных. Конкретные истории/предметы согласовать отдельно.
- scripts/home/home_exploration.gd: координация камеры/HUD/осмотра; соединяется с Session.home, запрашивает дневник/работу через сигналы. Не владеет часами смены.

Для нового тестового предмета добавить стабильный ID в HomeState.OBJECTS и HomeObject в Objects, указать якорь/текст/коллизию; сейчас один предмет на точку для кнопки осмотра. Для нового события добавить уникальный ID и список наблюдений в HomeState.EVENTS. Пока только простое условие «осмотрены все перечисленные предметы» и явное одноразовое завершение. Ветки, награды, инвентарь и произвольные условия не реализованы; их формат/контракт потребуют следующей задачи. После добавления предмета обновить счётчик 4 в HUD/проверках. Формат JSON диалогов не расширялся.

## Прогресс и интеграция

Main создаёт HomeExploration из отдельной сцены. Техническое смещение root=(32,0,0) изолирует коллизии от бара в общем World3D; это не география мира. Переходы происходят под прежним полноэкранным маршрутом, дома выбирается его Camera3D. Барная камера/цели заблокированы. Дом остаётся фоном для книги/меню, его HUD скрыт. Камера дома применяет текущие предпочтения DA-048 при возврате из меню.

Обычная следующая смена передаёт тот же HomeState вместе с Journal через RUN_HANDOFF; технический полный сброс создаёт новый. DA-032 записывает HomeState на успешном начале следующей смены после возвращения; изменения дома до этой границы ещё не записаны. См. [SAVES](SAVES.md). Новые позиционные звуки бара дома выключены по DA-048, прежний общий гул сохраняет исходное поведение.

NarrativeSession.configure_commute(panel, explorable_home=false) сохраняет fallback старого экрана для изолированных потребителей. Main передаёт true: CommutePanel показывает только дорогу, скрытые старые домашние кнопки не подключены к Session. Домашний UI — HomeExploration. Подробнее CONTRACTS/ADR-0018.

## Проверки

tools/check.ps1 включает tests/home_test.gd (прежние графовые контракты). Новый игровой путь отдельно: `tools/check_home_targets.ps1 -Godot <Godot 4.7.2> -Graphics`. Wrapper запускает home_target_test, прежний home_test и новый house_layout_test; с Graphics сохраняет 12 PNG в artifacts/da062 и 5 PNG в artifacts/house для каждого из normal/small. Общий runner не меняется параллельно: координатору добавить обе новые сцены при интеграции. Проверяются реальные лучи/курсор/четыре прежних предмета, дальность/стена/свежий луч, блокировки/возврат/осмотр/книга, событие/следующая смена и реальная ходьба/бытовые действия нового дома. Main-fixtures отключают пользовательские настройки/checkpoint. В редакторе запускать F5 через Main. Windows-экспорт и человеческая оценка остаются отдельной проверкой интеграции.
