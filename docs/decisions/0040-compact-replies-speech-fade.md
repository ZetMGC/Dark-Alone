# ADR-0040 — компактные ответы, затухание речи

Принято по прямому запросу владельца 2026-10-28. Панели ответов/действий измеряют строки вместо постоянного запаса 44/70; служебная строка скрыта с начала. [E] вынесена в колонку фиксированной ширины, одиночному ответу не нужен номер. Длинные варианты переносятся и прокручиваются при прежнем пределе высоты.

После завершения последней страницы текста речь остаётся на 3 с и затухает за 1.2 с. Исчезновение речевого пузырька не завершает диалог и не блокирует ответы/клавишу E. Промежуточная страница ждёт E; пауза и потеря фокуса останавливают таймер, новая страница/реплика восстанавливает видимость. Сохранения/содержание/канон не меняются.
