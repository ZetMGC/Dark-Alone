# ADR-0043 — возврат обзора после ЛКМ

Принято, DA-082, 2026-10-29: ошибка владельца воспроизводится после раскрытия речи кликом. Ответы освобождали курсор, а обзор не мог отвернуться от NPC. ЛКМ в режиме обзора сохраняет захват; открытый указатель ответов можно закрыть кликом по фону без отправки ответа. Флаг подавления удерживается до новой реплики/отведения взгляда. E и наведение строк сохранены, новые кнопки не добавлены.
