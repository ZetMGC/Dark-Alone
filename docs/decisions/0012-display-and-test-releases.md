# ADR-0012: Полный экран и проверяемые тестовые выпуски

Статус: accepted и implemented для DA-037. Дата: 2026-10-26.

## Контекст и решение

Владелец запросил работу под разные мониторы/разрешения и удобную передачу рабочих билдов. Используем обычный Godot Window.MODE_FULLSCREEN: покрывает текущий монитор без смены видеорежима; эксклюзивный режим не требуется. F11 и меню вызывают один DisplaySettings; список — фактические экраны DisplayServer. Возврат сохраняет оконную геометрию в памяти процесса, при другом экране ограничивает её рабочей областью. Встроенное окно редактора/headless не выдают ложный успех.

UI масштабируется canvas_items/expand от 1280×720 с равным масштабом по осям, вместо растяжения или фиксированных чёрных полей. Отдельный контроллер в Main, без autoload и зависимости от Session. Меню получает прокрутку настроек и отдельные постоянные кнопки продолжения/выхода. Сохранение предпочтений на диск не включено.

GitHub: уникальные prerelease-теги `v0.1.0-alpha.N`, проверенный чистый commit main, именованный ZIP + manifest + SHA256SUMS, сначала draft. tools/prepare_release.ps1 только подготавливает артефакты и отказывается от несинхронизированного main; публикация выполняется отдельным явным шагом. Публичность/лицензия не меняются, CI не добавлен. Порядок — RELEASES.

## Последствия

Нужно проверять компоновку/чтение на разных пропорциях и графический полноэкранный запуск: headless не проверяет мониторы. Масштабирование UI не ограничивает стоимость 3D на 4K; минимальное железо Q-07 остаётся открытым. Будущие выпуски не должны менять уже опубликованные артефакты под старым тегом. Более реалистичные записи дневника отложены в DA-038 до концепта владельца, вне этого решения.
