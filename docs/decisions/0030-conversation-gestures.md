# ADR-0030: опорная кисть и движения во время реплики

2026-10-28, CHAR-06, принято по скриншоту/прямому поручению второго участника.

VisitorModel сохраняет `talking: bool` как состояние разговора и добавляет `speaking: bool` — сейчас показывается текст реплики. `begin_line(key: String) -> void` начинает цикл новой реплики, выбирая повторяемый вариант по ключу dialogue_id:node_id. Это визуальные состояния, они не меняют Runner, ответы, эффекты или сохранения.

GuestArt слушает runner.node_changed и Session.mode_changed. Во время DIALOGUE и SERVICE с активным Runner разговор продолжается; speaking определяется через DialogueBubblePanel.is_line_complete(). В legacy-панели без печати speaking действует весь разговор. При ожидании ответа движения плавно затихают; следующая страница возобновляет их. Режимы меню/дневника выключают жесты, общий pause останавливает обработку дерева. Скрытая модель не обновляет позу.

Жесты выполняет свободная левая рука: пояснение, небольшой акцент, задумчивый наклон головы. Переходы сглажены, движения умеренные. Правая кисть остаётся на стойке: после позы вычисляется нижняя точка её skinned-вершин, небольшая поправка положения ForearmR удерживает её на высоте 1.16 м от пола гостя с зазором 3 мм. Коррекция ограничена 8 см. Это контакт для текущей TEST-стойки, не универсальный IK; при смене высоты стойки/посадки нужна настройка опоры. Запястья заходят внутрь манжет.

Потребители: GuestArt, visitor_model_test; Main/общие сцены не редактируются. GDScript-жесты и смена blink-текстур не запекаются в GLB. Озвучки/анимации губ в этой задаче нет.
