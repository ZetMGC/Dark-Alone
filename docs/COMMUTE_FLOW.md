# Переходы дом/работа — DA-031

## Как пройти

Закончить смену → «Домой · закончить день» → трёхсекундный TEST-переход → исследуемая 3D-комната DA-049 ([HOME](HOME.md)). Здесь 1–4 выбирают дверь/стол/окно/кровать, E или кнопка осматривают предметы, J открывает дневник. Вернуться к двери и нажать «На работу»: обратный переход создаёт Main заново у входа с 2 делениями и неподанным напитком. Переносятся Journal и HomeState, номер смены увеличивается. Только прямой «Сбросить тестовый прогресс» очищает оба вида прогресса.

«Пропустить переход» завершает текущую дорогу один раз. Escape приостанавливает маршрут и открывает меню; «Продолжить» возвращает к нему. В пути нельзя разговаривать, подавать напитки, открывать дневник или переходить по якорям. Прямой тестовый перезапуск из итогов сохранён.

## Границы модулей

`scripts/session/commute_flow.gd` — RefCounted с состояниями at_work/to_home/at_home/to_work/ready, read-only state/trip_id, методами start_home/start_work/complete(id) -> bool. Номер поездки растёт, неподходящие/старые ID и вложенные команды отклоняются. Модель не знает о времени, UI или мире.

`CommutePanel` и `commute_backdrop.gd` — UI дороги с параллаксом, travel_seconds=3.0. Tween приостанавливается в меню; таймер/пропуск испускают arrived(trip_id), Session проверяет режим/модель. В действующем Main панель видна только в пути, дома фон — сама комната. Старый плоский экран остаётся fallback для configure_commute(panel,false), при этом его слой 11 ниже книги.

Сессия предоставляет configure_commute(panel,explorable_home=false), go_home/go_to_work/finish_commute(id), режимы travel/home и сигнал new_shift_requested. Main передаёт true, подключает команды отдельного HomeExploration, старые домашние кнопки CommutePanel не подключаются. Journal и необязательный HomeState переносятся через одноразовую передачу SceneTree; ничего не пишется в user://. Основа — ADR-0009/0010, дом — ADR-0018.

## Проверка

```powershell
pwsh -NoProfile -File tools/check.ps1 -Godot godot
godot --path . --script tools/capture_commute_preview.gd --resolution 1280x720
godot --path . --script tools/capture_commute_preview.gd --resolution 960x600 -- --small
```

Снимки `artifacts/da031_*.png`: summary, to_home, pause, home, home_journal, to_work, new_shift; `_small` — минимальное окно. Смотреть отсутствие перекрытых кнопок/текста и фон дневника дома. Commute-test проверяет порядок/ID/повторы/паузы и настоящую перезагрузку Main, сквозной тест включает оба пути перезапуска. Экспорт — BUILD.

Графика маршрута — TEST-заготовка, без утверждения географии/событий/дизайна жилья. Реалистичный дневник и узнаваемые лица не реализованы этим этапом: для них отдельный [JOURNAL_PLAN](JOURNAL_PLAN.md). Механики и перенос знаний DA-033 реализованы — JOURNAL_CORE.
