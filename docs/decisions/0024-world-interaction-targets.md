# ADR-0024: Объекты вместо барных меток

Дата: 2026-10-27. Статус: принято по прямому запросу владельца. DA-058, уточняет способы входа ADR-0020/0021.

Владелец запросил наведение на стойку для открытия рабочего места и на посетителя для разговора. Оставляем E подтверждением, наведение показывает подсказку. При ходьбе используется прицел, на занятом месте курсор. Посетитель рядом может говорить без рабочего якоря, тело в разговоре заблокировано. Якорь остаётся внутренней позой рабочего места, а не видимой мишенью.

Физические коллизии стойки связываются с логическим WorkstationTarget через register_surface. Луч не перескакивает стены, повторяется при нажатии; цель проверяет доступность, Main — контекст/близость. У NPC область головы/тела, барные плавающие метки скрыты. Переход через клиентскую сторону не добавляется: рабочая зона остаётся за стойкой.

Изменение локально бару, без новой модели обслуживания/сюжета/арт-прохода/сохранений; дом прежний. Прежние графовые интерфейсы сохранены для legacy fixtures. Новые интерфейсы и потребители — [CONTRACTS](../CONTRACTS.md), управление/проверки — [WORLD_INTERACTION](../WORLD_INTERACTION.md).
