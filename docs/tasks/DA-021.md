# DA-021: Выбор реплик, дневник и UI

Статус: done. Владелец: агент DA-021. Ветка: `feat/DA-021-dialogue-journal`. База: `9a3510e`. Этап: M2, целиком ещё не закрыт.

## Результат

Игрок у стойки проходит любую из двух веток TEST-разговора, получает термины, читает дневник и возвращается к той же реплике. Модальные экраны блокируют камеру и навигацию. Завершение и прерывание различаются. Канонический сюжет, обслуживание, NPC и время не входят.

## Приёмка

- [x] Обе ветки и условия ответов исполняются по ID.
- [x] Термины и эффекты не дублируются в цикле, при повторном начале и перерисовке.
- [x] Дневник пустого/заполненного состояния работает, возвращает к той же реплике.
- [x] Камера, мир и старые кнопки не принимают действия через модальные экраны.
- [x] Finish выдаётся один раз, cancel не выдаёт finish; повторный разговор доступен.
- [x] E через луч и Tab/Enter проверены событиями движка, длинный текст просмотрен.
