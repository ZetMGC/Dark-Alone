godot --headless --path . --script res://tests/navigation_test.gd

Последняя команда выполняется отдельно: она не входит в скрипт Godot. Без PowerShell команды движка можно запускать напрямую на другой ОС. `godot` здесь — команда или путь к executable. При коде 0 всё равно проверить вывод на ошибки скриптов и ресурсов.

Smoke-тест загружает именно `application/run/main_scene`, создаёт её экземпляр и проверяет вход в дерево. Это узкая проверка готовности основы. Она не подтверждает игровые механики и качество изображения.

M0-экран заменён играбельной сценой. Ручной маршрут M1: F5 → вход → стойка → стол → угол → вход, затем обратный обход. Ошибки записать. Headless-проверка не оценивает комфорт обзора.

`tests/navigation_test.gd` автоматически проверяет восемь направленных связей, сигналы ровно один раз, отсутствие промежуточных поз камеры, сброс и ограничение обзора, блокировку ввода, события InputMap, команду HUD, коллизии конечных поз, ошибочные графы и перекрытие луча стеной.
