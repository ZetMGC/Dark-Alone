# Dark Alone {{TAG}} — тестовый билд

Коммит: `{{REVISION}}`. Windows x86_64, Godot 4.7.2, Compatibility.

## Что проверить

- Полный цикл: разговор, напиток, два деления смены, дорога домой и следующая смена.
- Дневник-книга: страницы/листание, поиск, новые записи, закладки и сохранение места чтения между обычными сменами.
- F11 или меню: окно/полный экран, выбор монитора. Проверить свой размер экрана и читаемость меню/дневника.
- Детализация мира: «Под экран», «Чёткая», «Классическая»; высокое разрешение теперь добавляет детали, шрифты MSDF.
- Меню «[TEST] Лицо гостя»: временные A/B/C, одинаковый игровой гость/заказ. Реалистичные персонажи — будущий художественный проход.

## Запуск

Скачать именованный Windows ZIP в Assets, распаковать целиком, запустить Dark Alone.exe. PCK должен лежать рядом. Godot устанавливать не нужно. Source code.zip — исходники, не готовая игра. Управление и маршрут проверки — START-HERE.md в архиве. Выход: Escape → «Выйти из игры».
