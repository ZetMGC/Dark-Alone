# ADR-0011: 2.5D-книга и курсор чтения

Статус: accepted и implemented для DA-034. Дата: 2026-10-26.

## Контекст

После DA-033 нужна убедительная книга с листанием, сохраняя читаемость кириллицы, знания между сменами и управление без рук. Полная 3D-книга потребовала бы мешей/камеры/текстур страниц или отдельного Viewport, дополнительной настройки резкости и синхронизации ввода. Для текущего модального чтения это не даёт необходимого игрового действия. 3D-вариант оценён по объёму реализации; отдельный 3D-прототип не создавался.

## Решение

Использовать 2.5D-рисунок Godot в существующем CanvasLayer 13: обложка, корешок, состаренная бумага и деформируемый лист, поверх чёткий UI. Системный serif-шрифт с fallback, без поставки стороннего файла шрифта. Собственный синтезированный шелест, отдельная громкость. Полные/короткие/отключённые анимации — предпочтения процесса.

Страницы вычисляются TextParagraph по реальной области текста. Journal хранит `reading_offset` в символах описания; UI переводит его в страницу. Данные фиксируются после успешного листания. Закрытие отменяет незавершённое действие, меню приостанавливает анимацию. Serial-токен защищает от устаревших callback. Прочитанность выбранной записи фиксируется после открытия.

Пользовательское закрытие идёт через `request_close_journal`, с сохранением блокировки мира до `close_completed`. Прежний `close_journal` остаётся синхронным принудительным закрытием для потребителей и проверок. Это сохраняет совместимость API. Новые интерфейсы и потребители перечислены в CONTRACTS.

## Последствия

Нет новых зависимостей, изменений JSON v1, графа якорей или схемы дискового сохранения. Пагинация меняется при другом шрифте/окне без переписывания прогресса. Будущая замена на 3D не должна менять модель записей. Сохранения должны учитывать смещение и изменение текста между версиями. Убедительность и ввод проверены автоматикой/изображениями локально; другая машина и пользовательская оценка остаются командной проверкой.
